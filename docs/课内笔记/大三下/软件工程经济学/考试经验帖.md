# 软件工程经济学考试经验帖

## 李彦筱

这门课程的考试形式是开卷考试，可以携带课本以及任何打印的笔记、ppt 等资料。考试包含填空题、简答题与计算题，其中填空题与简答题会从课本上直接选择部分内容出题，在考试中从课本上找到对应内容，照抄即可。计算题全部来源于之前做过的作业题，只要掌握了每章作业的解题方法就不用担心。

在准备填空题与简答题时，最好对照 [课程内容索引](docs/课内笔记/大三下/软件工程经济学/笔记/李彦筱/课程内容索引.md) 中的内容，将所有提到的知识点在课本上用荧光笔画出来，以便查阅时快速看到。有时间的话，可以略读一下课本，大致了解各个知识点都位于书的哪个章节，加快考试中翻书的速度。准备计算题时，只需要弄清所有作业题目的解法，最好掌握上方笔记中列出的所有计算题型。

考试时，可以打印所有章节的笔记、作业以及上述课程内容索引，并且记得带上课本。

## 袁泉

23级。授课老师是王晨旭老师。

带着金课之名，但实则不但过程并不煎熬，作业简单只点过一次名，而且考试又好过又好拿高分的一门课。

开卷考试，前50分填空和简答都能在开卷资料里找到几乎一模一样的表述，而且大多数不难找，看一眼就知道在哪一章。这部分得找和抄大概一小时。

后50分是计算题，题量大计算量大必须带计算器。大多数是作业原题，且老师最后一节课会上课讲评，有每道题的标准解析（有个别无关紧要的小错误），少数题后几问在原题上做了拓展，但ppt里能翻到类似的例题和公式照着写就行。考前花几个小时把这20道左右计算题自己熟悉和写一两遍，开卷资料带齐，这门课高分非常简单。唯一难点是时间挺紧的，计算题思路得熟悉，不少同学没写完。

资料准备建议：

- ppt：老师说考试内容都在ppt里，所以ppt是必须打印的，1000页。
- 最后一节课讲评的作业题解析：课后强烈建议在思源学堂录播截屏并全部打印，因为有的计算题真的除了数据一模一样，虽然你看懂了自己写也不难，但照着步骤写能快一点，否则容易写不完。
- （上面的ppt和作业题解析感觉必带，够你卷面90+了，下面两个可选）
- 学长整理的索引表+白色封皮旧版教材：全卷可能有一两个实在找不到的概念，可能看一眼索引表一下就找到了。
- 蓝色封皮的新版教材：这个我也带了但真没用上。
