# 软件工程-选修考试经验帖

## 袁泉

23级。授课老师是晋武侠老师。

这门课是23级第一次开课，课程标准可能不稳定还会有点变动。至少这一届课程很轻松，没考试是大作业，内容也不难，二选一。一个是单人vibe coding一个软件系统然后用10分钟汇报一下。一个是从老师发的论文里挑一篇讲解思路即可。

晋老师人很好，汇报的时候感觉是想方设法去夸你，最后给分也不错，不管台上同学表达能力如何都会尽可能找闪光点，就算有一眼全AI ppt糊上去像完全没准备的，老师也几乎没给上压力。

我选的是vibe coding一个系统，也没有多复杂。讲论文感觉比较难讲得出彩。比起技术深度老师似乎更看重两点：①你为什么做这个系统，老师喜欢比较有创意的。②你有没有试图去应用一些她上课讲的方法论，去结合课堂内容。

课程讲授的内容会比较杂，除了传统软工里的一些方法比如数据流分析、控制流分析这种，更多讲一点AI时代下的软件工程。主要是讲一些学术研究论文的内容，穿插一些实际AI开发的技巧，甚至有一些关于AI时代我们何去何从的探讨，我觉得还是比较深入的，真的会有所收获。虽然实操技巧似乎是不如跟自媒体博主学，但这门课在学校课程里已经算很紧跟时代的了。

不过作为大三下的专业选修，注定选课的人不会很多，小班上课自然点名就会比较多。

很推荐大二下跨选。
