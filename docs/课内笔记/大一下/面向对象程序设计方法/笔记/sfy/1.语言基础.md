# 1. 语言基础
## 1.1 了解Java语言的历史及Java程序的执行机制。

- Java语言的历史（了解）
	- 1991年：由Sun Microsystems的James Gosling领导的团队启动“Green Project”，旨在开发嵌入式系统语言。最初命名为Oak（橡树），后因商标问题更名为Java。  
	- **1995年：Java正式发布**，主打“一次编写，到处运行”（Write Once, Run Anywhere）的跨平台特性，借助 **JVM** 实现。  
	-  1996年：发布**JDK 1.0**，奠定Java基础语法与核心API。  
	- 1998年：**Java 2（J2SE 1.2）** 发布。
	- **2004年**：**Java 5**引入重大特性（泛型、注解、自动装箱、枚举等）。  
	-  2009年：Oracle收购Sun Microsystems，Java由Oracle主导发展。  
	- **2014年**：**Java 8**发布，支持Lambda表达式、Stream API等函数式编程特性。  
	- **2017年后**：版本更新加快，每半年发布一次，长期支持版本（LTS）如**Java 11**（2018）、**Java 17**（2021）成为主流。



- Java程序的执行机制
Java程序的执行基于 **“编译+解释”混合模式**，核心依赖**JVM（Java虚拟机）**。
	- **简略流程如下：  
源代码 → Java编译器 → 字节码 → JVM解释执行**
	- 详细流程（了解）：
	   - 开发者编写`.java`源代码文件。  
	   - javac编译器将源代码编译成字节码（`.class`文件），字节码是JVM的中间代码，与平台无关。
	   - JVM通过类加载器（ClassLoader）加载`.class`文件到内存。  
	   - 字节码验证器检查代码安全性（如内存访问、类型匹配），防止恶意代码。
	   - 解释执行：JVM逐行解释字节码为机器码执行。  
	   - JIT（即时编译器）优化：对高频代码（如循环）进行动态编译，生成本地机器码缓存，提升性能。  
	   - 内存管理：JVM通过垃圾回收器（GC）自动回收无用对象内存。  
	   - 异常处理：提供统一的异常处理机制。

 **1. 源文件创建**
- **规则**：
  - 文件名必须与`public`类名**完全一致**，扩展名为`.java`。
  - 一个文件可以包含多个类，但**只能有一个`public`类**。
- **示例**：
  ```java
  // File: Main.java
  public class Main { // 必须与文件名一致
      public static void main(String[] args) {
          System.out.println("Hello World");
      }
  }

  class Helper { // 非public类，可有多个
  }
  ```

 **2. 包声明（Package Declaration）**
- **规则**：
  - 包名通常为**小写字母**，采用逆域名格式（如`com.example.project`）。
  - 包声明必须在文件**首行**（注释除外）。
- **示例**：
  ```java
  package com.example.myapp; // 包声明

  public class Main {
      // ...
  }
  ```

 **3. 导入说明（Import Statements）**
- **规则**：
  - 导入语句位于包声明之后、类声明之前。
  - 可导入单个类或整个包（`*`）。
  - 静态导入（`import static`）用于导入类的静态成员。
- **示例**：
  ```java
  import java.util.ArrayList;     // 导入单个类
  import java.util.*;             // 导入整个包（不推荐，可能冲突）
  import static java.lang.Math.PI; // 静态导入
  ```

 **4. 类声明（Class Declarations）**
- **语法**：
  ```java
  [访问修饰符] class 类名 [extends 父类] [implements 接口1, 接口2] {
      // 成员变量
      // 方法
  }
  ```
- **示例**：
  ```java
  public class Dog extends Animal implements Runnable, Barkable {
      // 成员变量
      private String name;

      // 方法
      public void run() { /*...*/ }
  }
  ```

 **类类型**：
- **普通类**：`public class MyClass { ... }`
- **抽象类**：`public abstract class Animal { ... }`
- **内部类**：`class Outer { class Inner { ... } }`
- **静态嵌套类**：`class Outer { static class Nested { ... } }`

 **5. 接口声明与实现（Interface Declaration & Implementation）**
- **接口声明**：
  ```java
  public interface Runnable {
      void run(); // 默认public abstract
      default void log() { /* 默认方法 */ }
      static void staticMethod() { /* 静态方法 */ }
  }
  ```
- **接口实现**：
  ```java
  public class Dog implements Runnable {
      @Override
      public void run() { /* 必须实现抽象方法 */ }
  }
  ```

 **6. 方法声明（Method Declarations）**
- **语法**：
  ```java
  [访问修饰符] [static] [final] 返回类型 方法名(参数列表) [throws 异常] {
      // 方法体
  }
  ```
- **示例**：
  ```java
  public class Calculator {
      // 实例方法
      public int add(int a, int b) {
          return a + b;
      }

      // 静态方法
      public static double multiply(double x, double y) {
          return x * y;
      }

      // 主方法（程序入口）
      public static void main(String[] args) {
          Calculator calc = new Calculator();
          System.out.println(calc.add(2, 3));
          System.out.println(multiply(4.0, 5.0));
      }
  }
  ```

 **7. 变量声明与标识符（Variables & Identifiers）**

 **变量类型**：
- **局部变量**（方法内声明）：
  ```java
  public void myMethod() {
      int localVar = 10; // 必须显式初始化
  }
  ```
- **实例变量**（类内、方法外）：
  ```java
  public class MyClass {
      private int instanceVar; // 默认初始化（如int为0）
  }
  ```
- **静态变量**（类变量）：
  ```java
  public class MyClass {
      public static final double PI = 3.14159; // 常量
  }
  ```

 **标识符规则**：
1. 由字母、数字、`_`、`$`组成，不能以数字开头。
2. 不能是关键字（如`class`、`public`）。
3. 区分大小写。
- **示例**：
  ```java
  int age = 25;        // 合法
  String $name = "Tom"; // 合法
  double _score = 90.5; // 合法
  // int 2ndValue;     // 非法（以数字开头）
  ```

 **8. 完整示例**
```java
package com.example.demo;

import java.util.List;
import java.util.ArrayList;

public class Main implements Runnable {
    private static final String GREETING = "Hello"; // 静态常量

    private List<String> names; // 实例变量

    public Main() {
        names = new ArrayList<>();
    }

    @Override
    public void run() {
        System.out.println("Running...");
    }

    public static void main(String[] args) {
        Main app = new Main();
        app.names.add("Alice");
        app.run();
    }
}
```

 **基本数据类型（8个）**
- `boolean`：布尔类型，值为`true`或`false`，用于逻辑判断。
- `byte`：8位有符号整数，范围`-128`到`127`。
- `short`：16位有符号整数，范围`-32768`到`32767`。
- `int`：32位有符号整数，最常用的整型。
- `long`：64位有符号整数，声明时需加`L`（如`100L`）。
- `float`：32位单精度浮点数，声明时需加`F`（如`3.14F`）。
- `double`：64位双精度浮点数，最常用的浮点类型。
- `char`：16位Unicode字符，用单引号括起（如`'A'`）。

**引用数据类型**
- `class`：定义类的模板，包含属性和方法。
- `interface`：定义接口，包含抽象方法和常量。
- `enum`：定义枚举类型（Java 5+），表示一组命名的常量。

**访问控制关键字**
- `private`：限制成员只能在类内部访问。
- `protected`：允许同一包内或子类访问。
- `public`：允许所有访问。
- `default`（无关键字）：默认访问权限，仅限同一包内访问。

**流程控制关键字**
- **条件判断**
  - `if`：根据条件执行代码块。
  - `else`：与`if`搭配，条件不成立时执行。
  - `switch`：多分支选择，支持`case`和`default`。
- **循环**
  - `for`：基于计数的循环。
  - `while`：条件为真时循环。
  - `do-while`：先执行一次循环体，再判断条件。
- **跳转**
  - `break`：跳出当前循环或`switch`。
  - `continue`：跳过当前循环的剩余部分，继续下一次循环。
  - `return`：从方法返回值或结束方法。

 **异常处理关键字**
- `try`：尝试执行可能抛出异常的代码块。
- `catch`：捕获并处理特定类型的异常。
- `finally`：无论是否发生异常，都会执行的代码块。
- `throw`：手动抛出异常。
- `throws`：声明方法可能抛出的异常。

 **类和对象相关关键字**
- `class`：定义类。
- `interface`：定义接口。
- `extends`：继承类或实现接口。
- `implements`：实现接口。
- `new`：创建对象实例。
- `this`：引用当前对象实例。
- `super`：调用父类的构造方法或方法。
- `instanceof`：判断对象是否属于某个类或接口。

 **方法和构造器关键字**
- `void`：表示方法无返回值。
- `static`：声明静态成员（类级别的成员）。
- `final`：修饰类、方法或变量，表示不可继承、不可覆盖或不可修改。
- `abstract`：声明抽象类或方法（需在子类实现）。
- `synchronized`：确保线程安全，修饰方法或代码块。
- `native`：声明方法由其他语言（如C/C++）实现。
- `strictfp`：确保浮点运算遵循IEEE 754标准（Java 1.2+）。

 **修饰符关键字**
- `final`：防止继承（类）、覆盖（方法）或修改（变量）。
- `volatile`：确保变量的可见性和有序性（多线程中使用）。
- `transient`：标记变量不参与序列化。
- `synchronized`：控制多线程对共享资源的访问。
- `abstract`：声明抽象类或方法。
- `sealed`（Java 17+）：限制类或接口的继承。
- `non-sealed`（Java 17+）：允许类被继承（用于密封类）。

 **模块系统关键字（Java 9+）**
- `module`：定义模块。
- `requires`：声明模块依赖。
- `exports`：导出包供其他模块使用。
- `opens`：开放包以反射访问。
- `uses`：声明使用的服务。
- `provides`：声明提供的服务实现。

 **保留字（未使用的）**
- `const`：保留但未使用（历史上用于常量）。
- `goto`：保留但未使用（Java通过标签和`break/continue`模拟跳转）。

 **特殊字面量**
- `true`：布尔值“真”。
- `false`：布尔值“假”。
- `null`：引用类型的空值（表示无对象）。

**其他关键字**
- `assert`（Java 1.4+）：断言，用于调试（`assert condition;` 或 `assert condition : message;`）。
- `var`（Java 10+）：局部变量类型推断（仅用于局部变量）。
- `record`（Java 16+）：声明不可变的数据类（简化POJO）。
- `yield`（Java 13+）：在`switch`表达式中返回结果。

### 1.3.2 标识符构建规则
标识符用于命名类、方法、变量等，需遵循以下规则：

 **1. 语法规则**
- **允许字符**：  
  - 字母（A-Z, a-z）、数字（0-9）、下划线（`_`）、美元符号（`$`）  
  - Unicode字符（如中文，但不推荐）  
- **首字符**：  
  - 不能是数字（如 `2name` 非法）  
  - 可以是字母、`_`或`$`（如 `_count`、`$value` 合法）  
- **区分大小写**：`age` 和 `Age` 是不同的标识符  
- **长度限制**：无限制，但需保持简洁  
- **禁止使用关键词**：如 `int class = 5;` 非法  

**2. 命名约定（非强制，但强烈推荐）**
- **类名/接口名**：大驼峰式（`MyClass`、`Runnable`）  
- **方法名/变量名**：小驼峰式（`getUserName()`、`totalCount`）  
- **常量名**：全大写，下划线分隔（`MAX_SIZE`、`DEFAULT_TIMEOUT`）  
- **包名**：全小写，逆域名格式（`com.example.project`）  

 **3. 合法与非法示例**
| 合法标识符               | 非法标识符            | 原因                   |
|--------------------------|-----------------------|------------------------|
| `age` `_name` `$value`   | `123var`              | 以数字开头             |
| `userName` `MAX_VALUE`   | `class`               | 使用关键词             |
| `myVariable`             | `my-var`              | 包含非法字符（`-`）    |
| `ストリーム` (Unicode)   | `void`                | 使用关键词             |

**4. 特殊注意事项**
- **保留字**：`true`、`false`、`null`、`var` 等虽不是关键词，但也不能用作标识符。  
- **下划线与美元符号**：  
  - 避免单独使用（如 `_` 或 `$`），某些编译器可能警告。  
  - `$` 通常用于自动生成的代码（如内部类）。  



## 1.4 掌握变量的初始化以及数组类型变量的初始化。

Java中变量必须在使用前**显式或隐式初始化**，否则会编译错误。初始化方式因变量类型而异：

 **1. 变量分类**
| 变量类型       | 作用域               | 默认值       | 初始化要求           |
|----------------|----------------------|--------------|----------------------|
| **实例变量**   | 类内部（非static）   | 有默认值     | 可隐式初始化         |
| **类变量**     | 类内部（static）     | 有默认值     | 可隐式初始化         |
| **局部变量**   | 方法/代码块内部      | **无默认值** | **必须显式初始化**   |

**2. 默认值规则**
- **数值类型**：`0`（`int`/`short`/`byte`）、`0L`（`long`）、`0.0f`（`float`）、`0.0d`（`double`）
- **char**：`\u0000`（空字符）
- **boolean**：`false`
- **引用类型**：`null`

**3. 初始化示例**
```java
public class Example {
    // 实例变量（隐式初始化）
    private int age;        // 默认值为0
    private String name;    // 默认值为null

    // 类变量（隐式初始化）
    public static double PI = 3.14159; // 显式赋值覆盖默认值

    public void method() {
        // 局部变量必须显式初始化
        int count = 0;      // 必须赋值
        String msg;
        // System.out.println(msg); // 编译错误：未初始化
    }
}
```
***
**数组类型变量的初始化**
数组是**引用类型**，需通过`new`关键字或直接赋值初始化。

 **1. 一维数组初始化**
**方式1：静态初始化（直接赋值）**
```java
int[] arr1 = {1, 2, 3};             // 简写语法
String[] arr2 = new String[]{"A", "B"};
```
**方式2：动态初始化（指定长度）**
```java
int[] arr3 = new int[3];    // 默认值：0,0,0
String[] arr4 = new String[2]; // 默认值：null, null
arr3[0] = 10;               // 手动赋值
```
 **2. 多维数组初始化**
 **方式1：静态初始化**
```java
int[][] matrix1 = {
    {1, 2},
    {3, 4, 5}
};
```
**方式2：动态初始化**
```java
// 指定外层长度
int[][] matrix2 = new int[2][]; 
matrix2[0] = new int[2];    // 第一行2个元素
matrix2[1] = new int[3];    // 第二行3个元素

// 指定所有维度
int[][] matrix3 = new int[2][3]; // 2行3列的矩形数组
```

 **3. 数组默认值**
- **基本类型数组**：元素值为对应默认值（如`int[]`全为0）。
- **引用类型数组**：元素值为`null`，需逐个初始化：
  ```java
  String[] names = new String[3];
  names[0] = "Alice";       // 必须显式赋值
  ```
***
**关键注意事项**
- **局部变量必须显式初始化**：
   ```java
   void demo() {
       int x; 
       // System.out.println(x); // 编译错误！
   }
   ```
- **数组长度不可变**：初始化后长度固定，需用`ArrayList`等实现动态扩容。
- **内存分配**：
   - 数组是**堆内存对象**，变量名是引用（栈内存）。
   - 多维数组本质是“数组的数组”，允许非对称结构。
- **空指针风险**：
   ```java
   int[] arr = null;
   // System.out.println(arr[0]); // 运行时NullPointerException
   ```


## 1.5 了解所有基本数据类型的取值范围，掌握基本数据类型的常量表示形式。

Java 有 **8 种基本数据类型**，分为以下四类：
1. **整型**：`byte`、`short`、`int`、`long`  
2. **浮点型**：`float`、`double`  
3. **字符型**：`char`  
4. **布尔型**：`boolean`


| 类型   | 存储大小 | 取值范围 | 默认值 | 常量表示形式 | 示例代码 |
|--------|----------|----------|--------|--------------|----------|
| `byte` | 1 字节   | -128 ~ 127 | 0     | 直接赋值，或强制转换 `(byte)100` | `byte b = 100;` |
| `short`| 2 字节   | -32768 ~ 32767 | 0     | 直接赋值，或强制转换 `(short)2000` | `short s = 2000;` |
| `int`  | 4 字节   | -2^31 (-2147483648) ~ 2^31-1 (2147483647) | 0 | 直接赋值（默认整数类型） | `int i = 100000;` |
| `long` | 8 字节   | -2^63 ~ 2^63-1 | 0L    | 数值后加 `L` 或 `l`（如 `100L`） | `long l = 10000000000L;` |
| `float` | 4 字节   | 约 ±1.4E-45 ~ 3.4E38（有效小数位 6~7 位） | 0.0f | 数值后加 `F` 或 `f`（如 `3.14f`） | `float f = 3.14f;` |
| `double` | 8 字节   | 约 ±4.9E-324 ~ 1.8E308（有效小数位 15~17 位） | 0.0 | 直接赋值（默认浮点类型） | `double d = 3.14159;` |
| `char` | **2 字节**   | 0 ~ 65535（Unicode 字符） | `\u0000` | 单引号包裹字符（如 `'A'`）、转义字符（如 `'\n'`）、Unicode 转义（如 `'\u0041'`） | `char c = 'A';` |
| `boolean` | 1 位（逻辑） | `true` / `false` | `false` | 直接使用 `true` 或 `false` | `boolean flag = true;` |

1字节（byte） = 8位二进制


##  1.6掌握String、StringBuilder类型的基本使用。


**String 类**

- **不可变性**：`String` 对象一旦创建，其内容 **不可修改**。每次对字符串进行操作（如拼接、替换）都会生成一个新的 `String` 对象。
- **线程安全**：由于不可变性，`String` 是线程安全的。
- **常量池**：`String` 会利用常量池优化内存，重复的字符串会共享同一个对象。

```java
String str3 = new String(chars);

// 格式化字符串，类似于C++中的sprintf
String str = String.format("My age is %d", 18);  
```

输入输出

**StringBuilder 类**

- **可变性**：`StringBuilder` 对象的内容可以动态修改，不会生成新对象。
- **非线程安全**：由于可变性，`StringBuilder` 不是线程安全的（适合单线程场景）。
- **性能高**：适合频繁修改字符串的场景（如循环拼接）。

- **性能优化**：避免 `String` 多次创建新对象的开销。

---

**StringBuffer**与StringBuilder方法和写法几乎相同，但两者的 核心区别 在于 线程安全性和性能

StringBuffer：
- 所有公开方法（如 append、insert）都通过 synchronized 修饰，确保**线程安全**。
- **适用于多线程**：多线程环境下，多个线程同时操作 StringBuffer 对象时，不会出现数据不一致问题。
- **性能较低**：由于同步开销，执行速度略慢于 StringBuilder。

StringBuilder：
- 方法没有 synchronized 修饰，**非线程安全**。
- **适用于单线程**：如果多个线程同时修改 StringBuilder 对象，可能导致不可预期的结果。
- 单线程环境下，**性能更高**（无同步开销）。

---
**String vs StringBuilder**
| 对比维度         | `String`                          | `StringBuilder`                       |
|------------------|-----------------------------------|---------------------------------------|
| **可变性**       | 不可变                           | 可变                                 |
| **性能**         | 频繁修改时性能差（生成新对象）   | 高性能（直接修改内部字符数组）       |
| **线程安全**     | 安全（不可变）                   | 不安全（适合单线程）                 |
| **适用场景**     | 简单赋值、比较、少量操作         | 频繁拼接、修改（如循环、动态构建）   |
| **内部实现**     | 字符数组（`final char[] value`） | 字符数组（非 final，动态扩容）       |

```java

```


- **`String`**：适合静态字符串，内容不可变，操作简单但性能较低。
- **`StringBuilder`**：适合动态字符串，内容可变，性能高，适合频繁修改场景。
- **线程安全**：需要多线程安全时，使用 `StringBuffer`（线程安全的可变字符串类）。

#### java可以创建长度为0的数组吗？
Java **可以创建长度为0的数组**（无论是什么类型），这是完全合法的。java的数组长度不可修改，故长度为0的数组也无法添加或删除元素。零长度数组（空数组）在某些场景下非常有用，例如表示“没有元素”的集合，且比返回`null`更安全和规范。

**如何创建长度为零的数组？**
直接通过数组初始化语法即可：
```java
// 基本类型数组
int[] emptyIntArray = new int[0]; 
double[] emptyDoubleArray = {};

// 对象类型数组
String[] emptyStringArray = new String[0];
Object[] emptyObjectArray = {};
```

 **空数组的特性**
- **长度固定为0**：无法添加或删除元素。
- **内存分配**：空数组会占用少量内存（存储数组头信息），但远小于包含元素的数组。
- **非`null`**：空数组是有效的对象（`emptyArray != null`），而`null`表示未初始化。

**使用场景**
 **(1) 替代`null`返回值**
```java
// 返回空数组（推荐）
public String[] getNames() {
    return new String[0];
}

// 返回null（不推荐，可能引发NullPointerException）
public String[] getNames() {
    return null;
}
```
**优点**：调用方无需检查`null`，直接安全遍历：
```java
for (String name : getNames()) {
    // 即使数组为空，也不会报错
}
```

**(2) 不可变空集合**
空数组是天然不可变的（无法修改内容），适合作为常量：
```java
public static final String[] EMPTY_NAMES = new String[0];
```

**(3) 简化逻辑**
当方法需要返回数组，但可能没有实际数据时，空数组能简化代码逻辑：
```java
public String[] filterNames(List<String> list) {
    if (list == null) return new String[0];
    // ... 过滤逻辑 ...
    return resultList.toArray(new String[0]);
}
```

 **空数组与`null`的对比**
| **特性**               | **空数组**                 | **`null`**               |
|------------------------|---------------------------|--------------------------|
| 内存占用               | 少量内存（数组对象头信息） | 无内存占用               |
| 可操作性强弱           | 可安全调用`length`等方法  | 调用方法会抛`NullPointerException` |
| 代码健壮性             | 高（避免`NullPointer`）    | 低（需频繁判空）         |

注意：
- **性能优化**：频繁创建空数组可能产生冗余对象。可通过静态常量复用空数组：
  ```java
  public static final String[] EMPTY_STRING_ARRAY = new String[0];
  ```
- **集合转数组**：使用`toArray(new T[0])`更高效（Java 11+推荐）：
  ```java
  List<String> list = new ArrayList<>();
  String[] array = list.toArray(new String[0]); // 优于 list.toArray(new String[list.size()])
  ```

## 1.8 补充：类型转换

### 1.8.1 原始类型转换


在Java中，**原始数据类型（Primitive Types）的转换规则**分为**自动类型转换（隐式转换）**和**强制类型转换（显式转换）**

1. **自动类型转换（隐式转换）**
当**小范围类型**向**大范围类型**赋值时，Java会自动完成转换，无需显式声明。  
转换方向遵循以下优先级（范围从小到大）：  
```
byte → short → int → long → float → double  
          ↑  
          char → int → ...
```


```java
byte a = 10;
int b = a;      // 自动转换（byte → int）
char c = 'A';
int d = c;      // 自动转换（char → int，输出65）
double e = b;   // 自动转换（int → double）
```

 **规则细节**
- **整数到浮点数**：  
   `int` → `float` 或 `long` → `double` 可能丢失精度（浮点数的尾数位数有限）。
   ```java
   int x = 123456789;
   float y = x; // 精度丢失（float只能精确表示约6-7位有效数字）
   ```
- **char的特殊性**：  
   `char` 是无符号16位整数（范围 `0` 到 `65535`），与 `int` 自动兼容，但与 `byte`/`short` 需强制转换。

2. **强制类型转换（显式转换）**
当**大范围类型**赋值给**小范围类型**时，必须显式强制转换，但可能引发**数据丢失**或**精度损失**。


```java
目标类型 变量 = (目标类型) 源类型值;
```

```java
int a = 1000;
byte b = (byte) a;  // 强制转换（int → byte），可能溢出（结果为-24）
double d = 3.14;
int i = (int) d;    // 强制转换（double → int），结果为3（截断小数）
```

 **常见风险**
- **整数溢出**：  
   ```java
   int x = 200;
   byte y = (byte) x; // 结果为-56（超出byte范围-128~127）
   ```
- **浮点精度损失**：  
   ```java
   double d = 3.999;
   int i = (int) d;   // 结果为3（不四舍五入）
   ```
- **char与数值类型的转换**：  
   ```java
   int code = 65;
   char c = (char) code; // 'A'
   int num = (int) c;    // 65（自动转换）
   ```

3. **表达式中的自动类型提升**
在表达式中，操作数的类型会**自动提升到较大范围类型**再进行计算。
- `byte`/`short`/`char` 参与运算时，自动提升为 `int`。
- 若表达式中存在更大范围类型（如 `long`/`float`/`double`），则提升到最大范围类型。

```java
byte a = 10;
byte b = 20;
int c = a + b; // 必须用int接收（byte运算结果自动提升为int）

double x = 10.5;
int y = 3;
double z = x + y; // 结果为double（13.5）
```

4. **特殊类型说明**
- **boolean**：  
   无法与任何其他类型转换（非0/1逻辑）。
- **char与数值类型**：  
   - `char` → `int`/`long` 等：自动转换（取Unicode值）。  
   - `int` → `char`：需强制转换，保留低16位。

| **转换类型**       | **方向**            | **风险**                     | **示例**                  |
|--------------------|---------------------|-----------------------------|--------------------------|
| **自动转换**       | 小范围 → 大范围      | 浮点数精度损失               | `int → double`           |
| **强制转换**       | 大范围 → 小范围      | 数据溢出/精度截断            | `double → int`           |
| **表达式提升**     | 操作数自动提升       | 类型不匹配需强制转换          | `byte + byte → int`      |


**最佳实践**：  
- 避免不必要的强制转换，优先使用自动转换。  
- 强制转换前检查范围（如 `if (value >= Byte.MIN_VALUE && value <= Byte.MAX_VALUE)`）。  
- 浮点转整数时明确是否需要四舍五入（使用 `Math.round()`）。


### 1.8.2 引用类型可以强制类型转换吗？

在Java中，**引用类型可以进行强制类型转换**，但需要满足一定的条件，否则会导致运行时异常（`ClassCastException`）。以下是关键点和示例：

 **1. 强制类型转换的条件**
引用类型的强制转换需要满足以下**两种关系之一**：
- **继承关系**：目标类型是当前引用类型的父类或子类。
- **接口实现关系**：目标类型是当前引用类型实现的接口，或接口的实现类。

 **2. 向上转型 vs 向下转型**
| **类型**     | **方向**       | **安全性**                     | **是否需要强制转换**       |
|--------------|----------------|--------------------------------|--------------------------|
| **向上转型** | 子类 → 父类    | 安全（自动完成）               | 不需要（隐式转换）       |
| **向下转型** | 父类 → 子类    | 不安全（需确保对象实际类型匹配）| 需要显式强制转换         |

 **示例：向上转型（安全）**
```java
class Animal {}
class Dog extends Animal {}

Animal animal = new Dog(); // 向上转型（自动完成）
```

 **示例：向下转型（需显式强制转换）**
```java
Animal animal = new Dog();
Dog dog = (Dog) animal; // 强制转换（安全，因为实际对象是Dog）
```

**3. 运行时风险：`ClassCastException`**
如果**实际对象类型与目标类型不兼容**，强制转换会抛出异常：
```java
Animal animal = new Animal();
Dog dog = (Dog) animal; // 抛出 ClassCastException（实际对象是Animal）
```

 **4. 安全的强制转换方法**
在强制转换前，应使用 `instanceof` 检查类型：
```java
if (animal instanceof Dog) {
    Dog dog = (Dog) animal; // 安全转换
}
```

 **5. 接口与实现类的转换**
接口引用可以强制转换为具体的实现类（需确保实际对象类型匹配）：
```java
interface Flyable {}
class Bird implements Flyable {}

Flyable flyable = new Bird();
Bird bird = (Bird) flyable; // 强制转换为实现类
```
 **6. 特殊场景：无继承关系的转换**
如果两个类**没有继承或实现关系**，强制转换在编译时会直接报错：
```java
String str = "hello";
Integer num = (Integer) str; // 编译错误：不兼容的类型
```


 **总结**
| **场景**             | **是否允许强制转换** | **风险**                  |
|----------------------|----------------------|--------------------------|
| 父类 → 子类          | ✅ 允许（需显式转换） | 需确保实际类型匹配        |
| 子类 → 父类          | ✅ 允许（自动完成）   | 无风险（向上转型）        |
| 接口 → 实现类        | ✅ 允许（需显式转换） | 需确保实际类型匹配        |
| 无继承/实现关系      | ❌ 编译错误          | 无法通过编译              |

 **最佳实践**
1. **优先使用多态**：尽量通过接口或父类操作对象，减少强制转换。
2. **始终用 `instanceof` 检查**：确保向下转型的安全性。
3. **避免不必要的转换**：强制转换通常是设计上的妥协，需谨慎使用。


## 1.9 补充：负数取余

Java的取模运算（`%`）遵循以下规则：
- **结果的符号由被除数决定**，与除数的符号无关。
- **计算方式**：`被除数 - 除数 * (被除数 / 除数的整数商)`。

 **数学意义 vs Java结果**
- **数学模运算**：通常期望**结果符号与除数一致**，例如 `-6` 的数学模结果应为 `-4`（因为 `20 = (-6)*(-4) - 4`）。  
- **Java的`%`运算符**：更接近“取余”而非数学模运算，结果的符号由被除数决定。


 **补充**
若需符合数学模运算的结果，可以使用Java 8+的`Math.floorMod()`：
```java
System.out.println(Math.floorMod(20, -6)); // 输出 -4
```
