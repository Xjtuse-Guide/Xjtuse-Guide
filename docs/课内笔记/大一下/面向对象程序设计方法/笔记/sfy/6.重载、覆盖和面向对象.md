# 6. 重载、覆盖和面向对象
## 6.1 掌握面向对象的封装、继承和多态的概念，以及Java语言通过什么方式实现面向对象的这三大特征。


面向对象编程（OOP）的三大核心特征是 **封装**、**继承** 和 **多态**。它们是构建模块化、可维护和可扩展代码的基础。

### 6.1.1 封装（Encapsulation）
- **概念**：**将数据和操作数据的方法绑定在一个单元中，并对外隐藏内部实现细节，仅暴露必要的访问接口。**  
- **核心目的**：  
	- 保护数据不被非法修改（安全性）。  
	- 隐藏复杂性，简化外部使用（易用性）。  
- **Java 的实现方式**  
	- **访问修饰符**：  
	   - `private`：仅类内可访问。  
	   - `protected`：类内、子类和同包类可访问。  
	   - `public`：全局可访问。  
	   - 默认（无修饰符）：同包内可访问。  
	- **Getter/Setter 方法**：  
	   通过公共方法间接访问私有属性，控制读写逻辑。  


```java
public class Student {
    // 私有属性，外部无法直接访问
    private String name;
    private int age;

    // 公共方法暴露访问逻辑
    public String getName() {
        return name;
    }

    public void setName(String name) {
        if (name != null && !name.isEmpty()) {
            this.name = name;
        }
    }

    public int getAge() {
        return age;
    }

    public void setAge(int age) {
        if (age >= 0) { // 校验逻辑
            this.age = age;
        }
    }
}
```


### 6.1.2 继承（Inheritance）
- **概念** ：**允许一个类继承另一个类的属性和方法，并可以扩展或修改其行为。**  
- **核心目的**：  
	- 实现代码复用。  
	- 支持层次化设计（如“动物→猫/狗”）。  	
- **Java 的实现方式**  
	- **`extends` 关键字**：  
   ```java
   class Animal { }          // 父类
   class Dog extends Animal { } // 子类
   ```
	- **方法重写（Override）**：  
   子类可以重新定义父类的方法（需使用 `@Override` 注解）。  
	- **`super` 关键字**：  
   访问父类的属性、方法或构造器。  


```java
class Animal {
    public void eat() {
        System.out.println("动物在吃东西");
    }
}

class Dog extends Animal {
    @Override
    public void eat() {
        super.eat(); // 调用父类方法
        System.out.println("狗在啃骨头");
    }
}
```


### 6.1.3 多态（Polymorphism）
- **概念** ：同一操作作用于不同对象时，表现出不同的行为。  
- **两种类型**：  
	- **编译时多态**：方法重载（Overload）。  
	- **运行时多态**：方法重写（Override）和对象类型动态绑定。  
- **Java 的实现方式**  
	- **方法重写（Override）**：  
   子类重写父类方法，通过父类引用调用子类方法。  
	- **接口（`interface`）与实现类**：  
   通过接口类型引用不同实现类的对象。  
	- **向上转型（Upcasting）**：  
   父类引用指向子类对象，例如 `Animal dog = new Dog();`。  

```java
interface Shape {
    double area();
}

class Circle implements Shape {
    @Override
    public double area() {
        return Math.PI * radius * radius;
    }
}

class Square implements Shape {
    @Override
    public double area() {
        return side * side;
    }
}

public class Main {
    public static void main(String[] args) {
        Shape s1 = new Circle(5);    // 向上转型
        Shape s2 = new Square(4);    
        System.out.println(s1.area()); // 动态绑定到 Circle 的 area()
        System.out.println(s2.area()); // 动态绑定到 Square 的 area()
    }
}
```


### 6.1.4 java语言对 封装 继承 多态 的实现方式

| 特征   | 实现机制                                                                 |  
|--------|--------------------------------------------------------------------------|  
| **封装** | `private`/`protected` 修饰符 + Getter/Setter 方法                        |  
| **继承** | `extends` 关键字 + 方法重写 + `super` 关键字                             |  
| **多态** | 方法重写（Override） + 接口（`interface`） + 向上转型 + 动态绑定机制       |  

在Java中，静态绑定（Static Binding）和动态绑定（Dynamic Binding）是方法调用的两种不同机制，主要区别在于绑定的时机和依据：


### 6.1.5 理解静态绑定和动态绑定
 **1. 静态绑定（编译时绑定）**
- **定义**：在编译期间确定具体调用的方法或字段。
- **适用场景**：
  - **方法的重载**（根据参数类型和数量决定）。
  - **`private`、`static`、`final`方法**（无法被重写，编译时即可确定）。
  - **字段（成员变量）的访问**（字段不参与多态，由声明类型决定）。
- **特点**：
  - 基于**变量的声明类型**（编译时类型）。
  - 性能更高（无需运行时解析）。


```java
class A {
    static void print() { System.out.println("A"); }
    void show(int x) { System.out.println("A: int"); }
}

class B extends A {
    static void print() { System.out.println("B"); }  // 隐藏（非重写）
    void show(String s) { System.out.println("B: String"); }  // 重载
}

public class Main {
    public static void main(String[] args) {
        A a = new B();
        a.print();          // 输出 "A"（静态方法，静态绑定）
        a.show(10);         // 输出 "A: int"（重载，静态绑定）
    }
}
```

 **2. 动态绑定（运行时绑定）**
- **定义**：在运行期间根据对象的实际类型确定调用的方法。
- **适用场景**：
  - **方法的重写**（子类覆盖父类方法）。
  - **实例方法调用**（非`private`、`static`、`final`的方法）。
- **特点**：
  - 基于**对象的实际类型**（运行时类型）。
  - 支持多态，是面向对象的核心特性。

```java
class Animal {
    void sound() { System.out.println("Animal sound"); }
}

class Dog extends Animal {
    @Override
    void sound() { System.out.println("Bark"); }
}

public class Main {
    public static void main(String[] args) {
        Animal a = new Dog();
        a.sound();  // 输出 "Bark"（动态绑定，实际类型是Dog）
    }
}
```

 **常见误区**
- **字段（变量）没有多态**：
   ```java
   class Parent { int x = 1; }
   class Child extends Parent { int x = 2; }
   
   Parent p = new Child();
   System.out.println(p.x); // 输出 1（静态绑定，看声明类型Parent）
   ```

- **静态方法无法被重写**：
   ```java
   class Parent { static void foo() { System.out.println("Parent"); } }
   class Child extends Parent { static void foo() { System.out.println("Child"); } }
   
   Parent p = new Child();
   p.foo(); // 输出 "Parent"（静态绑定，看声明类型Parent）
   ```

- **构造函数中的动态绑定**：
   ```java
   class Parent {
       Parent() { print(); }  // 危险操作！调用子类重写的方法时，子类可能未初始化。
       void print() { System.out.println("Parent"); }
   }
   
   class Child extends Parent {
       int x = 1;
       @Override void print() { System.out.println(x); }  // 输出 0（未初始化）
   }
   ```



## 6.2 说明“是什么（is a）”和“有什么（has a）”之间关系的代码。


  * **"is-a" 关系** ：是继承关系的典型特征，**表示某个类是另一个类的子类**，即子类是超类的一种特殊情况。例如，"FloatingPointNumber is-a Number"（浮点数是数的一种），"Number is-a Object"（数是对象的一种）。在类层次结构中，这种关系构成了从超类到子类的层级继承体系，子类继承超类的属性和方法，实现代码的复用和扩展。
  * **"has-a" 关系** ：**表示一个类拥有或包含另一个类的实例作为其属性**，即类之间的一种关联关系，而不是继承关系。例如，"FloatingPointNumber has-a sign, a radix and a mantissa"（浮点数有一个符号、一个基数和一个尾数）。在类层次结构中，这种关系通常通过类的字段来体现，一个类可以通过其字段来引用其他类的对象，以实现对不同类对象的组合和利用，从而构建更复杂的数据结构和功能模块。

以下是具体代码示例：

- "is-a" 关系实例

```java
// Number 类作为父类
class Number {
    public void display() {
        // 显示数字信息
    }
}

// FloatingPointNumber 类继承自 Number 类，体现 "is-a" 关系
class FloatingPointNumber extends Number {
    private double value;

    public FloatingPointNumber(double value) {
        this.value = value;
    }

    @Override
    public void display() {
        // 显示浮点数信息
    }
}
```

- "has-a" 关系实例

```java
// FloatingPointNumber 类除了继承自 Number 外，还包含 sign, radix 和 mantissa 属性，体现 "has-a" 关系
class FloatingPointNumber extends Number {
    private boolean sign;   // 符号
    private int radix;      // 基数
    private double mantissa; // 尾数

    public FloatingPointNumber(boolean sign, int radix, double mantissa) {
        this.sign = sign;
        this.radix = radix;
        this.mantissa = mantissa;
    }

    public void displayDetails() {
        // 显示符号、基数和尾数的信息
    }
}
```

- 结合 "is-a" 和 "has-a" 的完整实例

```java
// Number 类保持不变
class Number {
    public void display() {
        // 显示数字信息
    }
}

// FloatingPointNumber 类同时展示了 "is-a" 和 "has-a" 关系
class FloatingPointNumber extends Number {
    private boolean sign;   // 符号
    private int radix;      // 基数
    private double mantissa; // 尾数
    private double value;    // 实际数值

    public FloatingPointNumber(boolean sign, int radix, double mantissa, double value) {
        this.sign = sign;
        this.radix = radix;
        this.mantissa = mantissa;
        this.value = value;
    }

    @Override
    public void display() {
        // 显示浮点数信息
    }

    public void displayDetails() {
        // 显示符号、基数、尾数和实际值的信息
    }
}
```

`FloatingPointNumber` 类通过继承 `Number` 类体现了 **"is-a"** 关系，并且通过包含额外的属性（如符号、基数和尾数）来展示 **"has-a**" 关系。

### 6.3.1 关于方法重写（覆盖）Override和方法重载Overload的区别

| **特性**       | **方法重写/覆盖（Override）**                          | **方法重载（Overload）**                          |
|----------------|--------------------------------------------------|--------------------------------------------------|
| **概念** | 子类重新定义父类中同名、同参数、同返回值的方法，以改变或扩展其行为。 | 在同一个类中，方法名相同但参数列表不同（参数类型、个数、顺序不同）。 |
| **目的**       | 子类重新定义父类的方法，实现多态性。              | 同一个类中定义多个功能相似但参数不同的方法。       |
| **发生范围**   | **子类**中继承父类的方法并重新实现。              | **同一个类**中定义多个同名方法。                  |
| **参数列表**   | **必须相同**（参数数量、类型、顺序完全一致）。    | **必须不同**（参数数量、类型或顺序至少有一个不同）。 |
| **返回类型**   | 必须与父类方法相同（Java 5+ 允许协变返回）。      | 可以相同也可以不同。                              |
| **访问权限**   | **不能比父类更严格**（如父类是 `protected`，子类可以是 `public`）。 | 可以任意修改（如 `private` 方法不能被重载为 `public`）。 |
| **异常处理**   | **子类抛出的异常必须与父类方法抛出的异常兼容**（更小或相等）。 | 可以抛出任意异常。                                |
| **实现机制**   | **运行时多态**（动态绑定）。                      | **编译时多态**（静态绑定）。                      |


- 方法名均必须相同
-  **方法重写不能修改参数列表**：  
   如果子类方法的参数列表与父类不同，编译器会报错（不是重写而是重载）。  

- **方法重载不能仅通过返回值类型区分**：  
   ```java
   // 错误示例：仅返回值类型不同，无法构成重载
   public int calculate() { ... }
   public double calculate() { ... } // 编译错误
   ```

- **`static` 方法不能被重写**：  
   静态方法属于类而非实例，子类中定义的同名静态方法会隐藏父类方法（不是重写）。  

- **`final` 方法不能被重写**：  
   `final` 方法被设计为不可修改，子类不能重写。  



### 6.3.2 Override和Overload的实现方式

**方法重写 Override**

- 子类覆写父类的方法 
```java
class Animal {
    public void makeSound() {
        System.out.println("动物发出声音");
    }
}

class Dog extends Animal {
    @Override  // 显式声明覆盖，提高可读性并帮助编译器检查
    public void makeSound() {
        System.out.println("汪汪");
    }
}
```
- 覆盖接口的抽象方法

```java
interface Shape {
    double area();  // 抽象方法
}

class Circle implements Shape {
    private double radius;

    @Override
    public double area() {
        return Math.PI * radius * radius;
    }
}
```

**方法重载 Overload**

- 参数类型不同

```java
public class Calculator {
    // 重载方法：参数类型不同
    public int add(int a, int b) {
        return a + b;
    }

    public double add(double a, double b) {
        return a + b;
    }
}
```

- 参数个数不同

```java
public class Printer {
    // 重载方法：参数个数不同
    public void print(String text) {
        System.out.println(text);
    }

    public void print(String text, int copies) {
        for (int i = 0; i < copies; i++) {
            System.out.println(text);
        }
    }
}
```


- 参数顺序不同

```java
public class Converter {
    // 重载方法：参数顺序不同
    public void convert(int a, String b) { /* ... */ }

    public void convert(String a, int b) { /* ... */ }
}
```
