# 3. 流控制和异常处理
## 3.1 使用if和switch编写分支代码。


### 3.1.1 **`if` 语句** 


**单分支 `if`**
```java
if (条件) {
    // 条件为 true 时执行的代码
}
```


**双分支 `if-else`**
```java
if (条件) {
    // 条件为 true 时执行
} else {
    // 条件为 false 时执行
}
```


 **多分支 `if-else if-else`**
```java
if (条件1) {
    // 条件1 为 true 时执行
} else if (条件2) {
    // 条件2 为 true 时执行
} else {
    // 所有条件都不满足时执行
}
```

**嵌套 `if`**
```java
if (外层条件) {
    if (内层条件) {
        // 内层条件为 true 时执行
    }
}
```

 **三目运算符（简化双分支）**
```java
变量 = (条件) ? 表达式1 : 表达式2;
```
```java
int a = 10, b = 20;
int max = (a > b) ? a : b;
System.out.println("最大值是: " + max);
```


### 3.1.2 **`switch` 语句**

`switch` 语句适用于 **多个离散值的匹配**，代码更简洁。从 Java 7 开始支持 `String` 类型，Java 12+ 引入了更简洁的箭头语法。

```java
switch (表达式) {
    case 值1:
        // 匹配值1时执行
        break;
    case 值2:
        // 匹配值2时执行
        break;
    default:
        // 默认情况
}
```

**`case` 穿透（无 `break` 时）**
```java
switch (表达式) {
    case 值1:
    case 值2:
        // 值1 和 值2 共享同一段代码
        break;
}
```
```java
int n = 2;
switch (n) {
    case 1:
    case 2:
        System.out.println("1 或 2");
        break;
    case 3:
        System.out.println("3");
        break;
}
```

**支持 `String` 类型（Java 7+）**
```java
String fruit = "apple";
switch (fruit) {
    case "apple":
        System.out.println("苹果");
        break;
    case "banana":
        System.out.println("香蕉");
        break;
    default:
        System.out.println("未知水果");
        break;
}
```
**Java 12+ 新语法（箭头表达式）**
```java
String result = switch (表达式) {
    case 值1 -> "结果1";
    case 值2 -> "结果2";
    default -> "默认结果";
};
```
```java
int day = 3;
String dayType = switch (day) {
    case 1, 2, 3, 4, 5 -> "工作日";
    case 6, 7 -> "周末";
    default -> "无效";
};
System.out.println(dayType);
```



**注意事项**：
   - **`switch` 的 `case` 穿透**：忘记 `break` 会导致代码继续执行后续 `case`。
   - **使用 `default` 或 `else`**：处理未覆盖的边界情况，避免逻辑漏洞。
   - `switch` 箭头表达式不用人为加 `break`
   - 一般把 `default` 语句放在最后，但实际上无论放哪都不影响结果




## 3.2 使用各种形式的循环语句编写迭代代码，包括标签的和未标签的break和continue语句使用。


1. 标准 `for` 循环
```java
// 遍历数组
int[] numbers = {1, 2, 3, 4, 5};
for (int i = 0; i < numbers.length; i++) {
    System.out.println(numbers[i]);
}

// 嵌套 for 循环
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        System.out.println(i + "x" + j + " = " + (i * j));
    }
}
```

2. 增强 `for-each` 循环
```java
// 遍历数组
int[] nums = {10, 20, 30};
for (int num : nums) {
    System.out.println(num);
}

// 遍历集合
List<String> fruits = Arrays.asList("Apple", "Banana", "Cherry");
for (String fruit : fruits) {
    System.out.println(fruit);
}

// 遍历 Map
Map<String, Integer> ages = new HashMap<>();
ages.put("Alice", 25);
ages.put("Bob", 30);
// 遍历键值对
for (Map.Entry<String, Integer> entry : ages.entrySet()) {
    System.out.println(entry.getKey() + " is " + entry.getValue() + " years old");
}
// 仅遍历键
for (String name : ages.keySet()) {
    System.out.println("Name: " + name);
}
// 仅遍历值
for (int age : ages.values()) {
    System.out.println("Age: " + age);
}
```

3. `while` 循环
```java
// 条件控制的循环
int count = 0;
while (count < 5) {
    System.out.println("Count: " + count);
    count++;
}

// 处理输入直到特定条件
Scanner scanner = new Scanner(System.in);
String input;
while (!(input = scanner.nextLine()).equals("exit")) {
    System.out.println("You entered: " + input);
}
```

4. `do-while` 循环
```java
// 至少执行一次
int x = 5;
do {
    System.out.println("x = " + x);
    x--;
} while (x > 0);
```


**`break` 和 `continue` 语句**

- 未标签的 `break` 和 `continue`
```java
// break 终止当前循环
for (int i = 0; i < 10; i++) {
    if (i == 5) {
        break; // 当 i=5 时退出循环
    }
    System.out.println(i);
}

// continue 跳过当前迭代
for (int i = 0; i < 5; i++) {
    if (i == 2) {
        continue; // 跳过 i=2 的迭代
    }
    System.out.println(i);
}
```

- 带标签的 `break` 和 `continue`
```java
// 标签用于控制多层循环
outerLoop:
for (int i = 0; i < 3; i++) {
    innerLoop:
    for (int j = 0; j < 3; j++) {
        if (i == 1 && j == 1) {
            break outerLoop; // 直接退出外层循环
        }
        if (j == 2) {
            continue innerLoop; // 跳过内层循环的当前迭代
        }
        System.out.println(i + ", " + j);
    }
}
```


## 3.3 掌握Java的异常类型的组织结构。

![在这里插入图片描述](https://telegraph-image-5ms.pages.dev/file/AgACAgUAAyEGAASIfjD1AAIC52qNr_IUvaGlP8LAsAtEhDwnrgfxAAIuF2sb5mpoVCyHRhyrxPkhAQADAgADeQADPQQ.png)
**运行时异常**都是**RuntimeException类及其子类异常**， 均为**非检查型异常**，程序中可以选择捕获处理，也可以不处理。这些异常一般是由程序逻辑错误引起的，程序应该从逻辑角度尽可能避免这类异常的发生。如果发生了异常且该未处理的异常是从主线程抛出的，程序依旧会终止。

**非运行时异常**是**RuntimeException以外的异常**，均为**检查型异常**。是必须进行处理的异常，如果不处理，程序就不能编译通过。


**检查型异常（Checked Exceptions）**

| 异常类型 | 描述 | 示例场景 |
|---------|------|----------|
| `IOException` 常用| 输入/输出操作失败（如文件读写、网络连接）。 | 读取文件时文件不存在或权限不足。 |
| `SQLException` | 数据库访问异常（如 SQL 语法错误、连接失败）。 | 执行 SQL 查询时表不存在。 |
| `ClassNotFoundException` | 加载类时未找到对应的类。 | 使用 `Class.forName()` 加载类时路径错误。 |
| `NoSuchMethodException` | 反射调用方法时未找到对应方法。 | 使用 `Method.invoke()` 调用不存在的方法。 |
| `FileNotFoundException` | 文件未找到。 | 打开不存在的文件时抛出。 |
| `EOFException` | 读取文件时遇到意外结束。 | 文件未完整读取即被关闭。 |
| `MalformedURLException` | URL 格式错误。 | 解析非法 URL 时抛出。 |
| `InterruptedException` | 线程被中断时抛出。 | 调用 `Thread.sleep()` 时线程被其他线程中断。 |
| `NoSuchFieldException` | 反射调用字段时未找到对应字段。 | 使用 `Field.get()` 访问不存在的字段。 |
| `InvalidClassException` | 序列化时类版本不兼容。 | 反序列化对象时类结构不匹配。 |



**非检查型异常（Unchecked Exceptions）**

| 异常类型 | 描述 | 示例场景 |
|---------|------|----------|
| `ArithmeticException` 常用 | 数学运算异常（如除以零）。 | `int result = 10 / 0;` |
| `ArrayIndexOutOfBoundsException` | 数组越界访问。 | `arr[10]`（数组长度为 5）。 |
| `ArrayStoreException` | 错误类型存储到数组中。 | 将字符串存入整型数组。 |
| `ClassCastException` | 类型转换失败。 | `List<String> list = (List<String>) (List<Integer>) new ArrayList<>();` |
| `NullPointerException` | 使用 `null` 对象时抛出。 | `String str = null; str.length();` |
| `IllegalArgumentException` | 传递非法参数给方法。 | `new ArrayList<>(-1);`（集合初始化容量为负数）。 |
| `IllegalStateException` | 方法在对象的不合适状态下被调用。 | 在未初始化的集合上调用 `add()`。 |
| `NumberFormatException` | 字符串转换为数字失败。 | `Integer.parseInt("abc");` |
| `StringIndexOutOfBoundsException` | 字符串访问时索引超出界限。 | `str.charAt(10)`（字符串长度为 5）。 |
| `UnsupportedOperationException` | 对象不支持请求的操作。 | 调用 `Collections.unmodifiableList()` 的 `add()` 方法。 |



内置异常方法

| 方法 | 描述 |
|------|------|
| `getMessage()` 常用| 返回异常的详细消息字符串（如 "文件未找到"）。 |
| `getCause()` | 返回导致当前异常的 **根本原因**（如果存在）。 |
| `printStackTrace()` | 打印异常的堆栈跟踪（包括异常类型、消息、方法调用链）。 |
| `toString()` | 返回异常的简短描述（如 `java.lang.NullPointerException`）。 |
| `fillInStackTrace()` | 填充异常的堆栈跟踪信息（通常用于调试）。 |
| `getStackTrace()` 常用 | 返回堆栈跟踪元素的数组。 |
| `initCause(Throwable cause)` | 设置异常的原始原因（用于异常链）。 |
| `addSuppressed(Throwable exception)` | 添加被抑制的异常（在 `try-with-resources` 中使用）。 |



## 3.4 编写使用异常和异常处理子句（try、catch、finally）的代码，以及编写带有异常处理的方法声明。

异常处理Exception Handling

在Java中，异常处理是一种机制，用于在程序运行时捕获和处理错误或异常情况，从而避免程序崩溃并提供更友好的错误提示。Java提供了`try`、`catch`、`finally` 和 `throw` 等关键字来实现异常处理，并允许方法声明可能抛出的异常。

### 3.4.1 使用 try-catch-finally 处理异常

```java
try {
    // 可能会引发异常的代码块
} catch (ExceptionType1 e) { // e为该异常实例的变量名 可以取任何合法的名字
    // 处理异常类型 1 的代码
} catch (ExceptionType2 e) {
    // 处理异常类型 2 的代码
} finally {
    // 无论是否发生异常，都会执行的代码（例如资源释放），也可以不写
}
```

- **try 块**：包含可能会抛出异常的代码。
- **catch 块**：捕获特定类型的异常并进行处理。可以有多个 `catch` 块来处理不同类型的异常。
- **finally 块**：无论是否发生异常，都会执行的代码块，通常用于释放资源（如关闭文件、数据库连接等）。可不写。


```java
public class ExceptionHandlingExample {
    public static void main(String[] args) {
        try {
            int result = divide(10, 0);  // 调用可能导致异常的方法
            System.out.println("Result: " + result);
        } catch (ArithmeticException e) {
            System.out.println("捕获到算术异常: " + e.getMessage());
        } finally {
            System.out.println("执行 finally 块，清理资源");
        }
    }

    public static int divide(int a, int b) {//ArithmeticException 为非检查型异常，不需要在方法中声明
        return a / b;  // 当 b 为 0 时，会抛出 ArithmeticException
    }
}
```
输出：
```
捕获到算术异常: / by zero
执行 finally 块，清理资源
```


### 3.4.2 异常处理的方法声明

在Java中，如果一个方法内部无法处理异常，可以通过 `throws` 关键字将异常传递给调用者。调用者可以选择捕获该异常或者继续向上传递。
```java
returnType methodName(parameters) throws ExceptionType1, ExceptionType2 {
    // 方法体
}
```
- 如果方法可能会抛出检查型异常（checked exception），则必须使用 `throws` 显式声明这些异常。
- 非检查型异常（unchecked exception，如 `RuntimeException` 或其子类）不需要强制声明。

```java
import java.io.*;

public class MethodThrowsExample {
    public static void main(String[] args) {
        try {
            readFile("example.txt");  // 调用可能会抛出异常的方法
        } catch (IOException e) {
            System.out.println("捕获到IO异常: " + e.getMessage());
        }
    }

    // 声明该方法可能抛出 IOException
    public static void readFile(String fileName) throws IOException {
        FileReader fileReader = new FileReader(fileName);  // 如果文件不存在，会抛出 FileNotFoundException
        int data;
        while ((data = fileReader.read()) != -1) {  // 读取文件内容
            System.out.print((char) data);
        }
        fileReader.close();
    }
}
```

### 3.4.3 `try` 后必须紧跟 `catch` ？

**不一定**，具体取决于是否使用 `finally` 或 `try-with-resources` 语法。

| **情况**               | **是否合法** | **说明**                                                                 |
|------------------------|--------------|--------------------------------------------------------------------------|
| `try` 单独使用          |  否         | 必须搭配 `catch` 或 `finally`。                                          |
| `try + catch`           |  是         | 捕获并处理异常。                                                         |
| `try + finally`         |  是         | 无论是否异常，`finally` 块都会执行（用于资源清理）。                     |
| `try + catch + finally` |  是         | 同时捕获异常并执行资源清理。                                             |
| `try-with-resources`    |  是         | 自动关闭资源，可省略 `catch` 或 `finally`（但建议保留 `catch` 处理异常）。 |


- `try` 块可以不带 `catch`，但必须有 `finally`。  
- `try` 必须配合 `catch` 或 `finally`，但 `try-with-resources` 可以例外。  
- `try` 后不需要强制跟 `catch`，可以只用 `finally`。  
- `catch` 和 `finally` 不能同时不出现，但可以单独使用其中一个。  

通过合理使用 `try-catch-finally` 或 `try-with-resources`，可以编写健壮且资源友好的代码。




### 3.4.4 理解抛异常

在Java中，当程序发生异常并且没有被捕获时，异常会沿着调用栈向上传播，直到被某个`try-catch`块捕获或到达最顶层。一旦异常被捕获并处理，程序将继续执行`catch`块之后的代码。如果异常到达最顶层而没有被捕获，程序会终止执行，并输出详细的错误信息和堆栈跟踪。

写抛异常就是为了允许程序从错误状态中恢复，而非发生异常后完全崩溃。

具体来说：

1. **异常抛出**：当程序遇到错误条件时，会抛出一个异常对象。
2. **异常传播**：如果没有立即捕获异常，异常会在调用栈中逐层向上传播，直到找到一个匹配的`catch`块或到达最顶层。
3. **异常捕获**：如果找到了匹配的`catch`块，异常会被捕获，并执行相应的`catch`块中的代码。
4. **继续执行**：在`catch`块执行完毕后，程序会继续执行`catch`块之后的代码，而不是回到异常发生的点重新开始执行。

下面是一个详细的示例来说明这个过程：

```java
public class ExceptionHandlingExample {
    public static void main(String[] args) {
        System.out.println("程序开始...");

        try {
            int result = divide(10, 0); // 这将抛出ArithmeticException
            System.out.println("除法结果: " + result);
        } catch (ArithmeticException e) {
            System.out.println("捕获到异常: " + e.getMessage());
        }

        System.out.println("程序继续执行...");
    }

    public static int divide(int a, int b) {
        return a / b; // 这里会发生除零错误
    }
}
```

在这个示例中：

1. `main`方法中调用了`divide`方法。
2. `divide`方法尝试进行除以零的操作，这会抛出`ArithmeticException`。
3. 异常从`divide`方法传播回`main`方法中的`try`块。
4. `try`块中的代码在异常发生的地方停止执行。
5. `catch`块捕获了`ArithmeticException`并打印了错误信息。
6. 在`catch`块执行完毕后，程序继续执行`catch`块之后的代码，即打印“程序继续执行...”。

只有`try`块中从异常发生点开始的部分代码会终止，而`catch`块和其后的代码会继续执行。这就避免了程序完全崩溃。


**总结**

| 关键词/语句 | 功能 |
|-------------|------|
| `try`       | 包含可能会引发异常的代码块 |
| `catch`     | 捕获并处理特定类型的异常 |
| `finally`   | 无论是否发生异常，都会执行的代码块 |
| `throws`    | 在方法签名中声明可能抛出的异常 |
| `throw`     | 在代码中显式抛出异常 |

- 尽量只捕获特定类型的异常，而不是直接捕获 `Exception` 类。
- 使用 `finally` 块确保资源被正确释放。


## 3.5 掌握自定义异常类类型及相关使用。

抛出自定义异常：除了使用Java内置的异常类外，还可以通过继承 `Exception` 或其子类来创建自定义异常。
自定义异常默认会继承 Exception 或者 RuntimeException。继承 Exception 的异常默认是受查异常，继承于 RuntimeException 的异常默认是非受查异常。

**自定义异常类**
```java
// 自定义异常类
class InvalidAgeException extends Exception {
    public InvalidAgeException(String message) {
        super(message);
    }
}
```

**在方法中抛出异常**
```java
public class CustomExceptionExample {
    public static void main(String[] args) {
        try {
            checkAge(15);  // 调用检查年龄的方法
        } catch (InvalidAgeException e) {
            System.out.println("捕获到自定义异常: " + e.getMessage());
        }
    }

    // 检查年龄的方法
    public static void checkAge(int age) throws InvalidAgeException {
        if (age < 18) {
            throw new InvalidAgeException("年龄小于18岁，不允许注册！");
        } else {
            System.out.println("年龄合法，可以注册！");
        }
    }
}
```
