# 2. 运算符和函数
## 2.1 掌握运算符（包括运算符的优先级、结合性以及计算）。

Java运算符的优先级从高到低的完整列表：

| **优先级** | **运算符**                                                                 | **结合性** | **说明**                                                                 |
|------------|---------------------------------------------------------------------------|------------|--------------------------------------------------------------------------|
| **1**      | `[]`、`()`、`{}`（数组索引、方法调用、对象创建）                          | 左 → 右    | 后缀运算符（括号、数组访问、对象初始化）                                  |
| **2**      | `++`、`--`（后缀）                                                        | 左 → 右    | 后缀自增/自减运算符                                                      |
| **3**      | `++`、`--`、`+`、`-`、`~`、`!`、`(type)`（前缀）                          | 右 → 左    | 前缀自增/自减、正负号、按位取反、逻辑非、类型转换                         |
| **4**      | `*`、`/`、`%`                                                             | 左 → 右    | 乘法、除法、取模运算                                                     |
| **5**      | `+`、`-`                                                                  | 左 → 右    | 加法、减法（也用于字符串拼接）                                            |
| **6**      | `<<`、`>>`、`>>>`                                                         | 左 → 右    | 左移、带符号右移、无符号右移                                             |
| **7**      | `<`、`<=`、`>`、`>=`、`instanceof`                                        | 左 → 右    | 比较运算符（关系运算）                                                   |
| **8**      | `==`、`!=`                                                                | 左 → 右    | 相等性比较运算符                                                         |
| **9**      | `&`（按位与/布尔与）                                                      | 左 → 右    | 按位与运算符（非短路）                                                   |
| **10**     | `^`（按位异或）                                                           | 左 → 右    | 按位异或运算符                                                           |
| **11**     | `\|`（按位或/布尔或）                                                       | 左 → 右    | 按位或运算符（非短路）                                                   |
| **12**     | `&&`（短路与）                                                            | 左 → 右    | 逻辑与（短路）                                                           |
| **13**     | `\|\|`（短路或）                                                            | 左 → 右    | 逻辑或（短路）                                                           |
| **14**     | `? :`（条件运算符）                                                       | 右 → 左    | 三目条件运算符（从右向左结合）                                           |
| **15**     | `=`、`+=`、`-=`、`*=`、`/=`、`%=`、`<<=`、`>>=`、`>>>=`、`&=`、`^=`、`\|=` | 右 → 左    | 赋值运算符（右结合性）                                                   |

**(1) 优先级决定运算顺序**

```java
int result = 5 + 3 * 2; 
// 由于 `*` 的优先级高于 `+`，先计算 `3 * 2`，再执行加法：  
// 等价于 5 + (3 * 2) → 5 + 6 = 11
```

```java
int result = 5 * 3 % 2; 
// `*` 和 `%` 优先级相同，结合性为左 → 右，先计算 `5 * 3`，再取模：  
// 等价于 (5 * 3) % 2 → 15 % 2 = 1
```
**(2) 结合性决定同级运算的顺序**
```java
int result = 8 / 4 / 2; 
// `/` 是左结合，先计算 `8 / 4`，再除以 2：  
// 等价于 (8 / 4) / 2 → 2 / 2 = 1
```
```java
int a = 10, b = 20, c = 30;
int result = a = b = c; 
// `=` 是右结合，先计算 `b = c`（b=30），再将结果赋给 a：  
// 等价于 a = (b = c) → a=30, b=30
```



## 2.2 掌握函数参数的传递（包括值传递和引用传递）。

 **1. 基本数据类型的值传递**
基本数据类型（如 `int`、`double`、`char` 等）在传递时，传递的是**值的副本**。方法内部对参数的修改不会影响到原始变量。


```java
public class ValuePassingExample {
    public static void modifyValue(int a) {
        a = 100; // 修改的是副本
        System.out.println("方法内 a 的值: " + a);
    }

    public static void main(String[] args) {
        int a = 5;
        System.out.println("调用前 a 的值: " + a);
        modifyValue(a);
        System.out.println("调用后 a 的值: " + a); // 原始值未改变
    }
}
```

- **输出结果：**
```
调用前 a 的值: 5
方法内 a 的值: 100
调用后 a 的值: 5
```

- **解释：**
方法 `modifyValue` 接收到的是 `a` 的副本（值为 5），修改副本的值不会影响原始变量 `a`。


**2. 引用类型的值传递**
引用类型（如对象、数组等）在传递时，传递的是**引用的副本**（即对象在堆内存中的地址）。方法内部可以通过引用副本修改对象的内容，但无法改变原始引用的指向。

**(1) 修改对象的属性**
通过引用副本可以修改对象的内部状态，但不会影响原始引用的指向。


```java
class Person {
    String name;

    public Person(String name) {
        this.name = name;
    }

    public void setName(String name) {
        this.name = name;
    }
}

public class ReferencePassingExample {
    public static void modifyName(Person person) { // person为p的副本
        person.setName("Alice"); // 修改对象的属性
        System.out.println("方法内 person.name: " + person.name);
    }

    public static void main(String[] args) {
        Person p = new Person("Bob"); // p 为原始引用
        System.out.println("调用前 p.name: " + p.name);
        modifyName(p);
        System.out.println("调用后 p.name: " + p.name); // 对象属性被修改
    }
}
```
- **输出结果：**
```
调用前 p.name: Bob
方法内 person.name: Alice
调用后 p.name: Alice
```

- **解释：**
方法 `modifyName` 接收到的是 `p` 的引用副本（指向堆中的 `Person` 对象），修改对象属性会直接影响原始对象。

**(2) 重新赋值引用**
如果方法内将引用副本指向新的对象，原始引用不会受到影响。

```java
public class ReferencePassingExample2 {
    public static void changeReference(Person person) {
        person = new Person("Charlie"); // 引用副本指向新对象
        System.out.println("方法内 person.name: " + person.name);
    }

    public static void main(String[] args) {
        Person p = new Person("Bob");
        System.out.println("调用前 p.name: " + p.name);
        changeReference(p);
        System.out.println("调用后 p.name: " + p.name); // 原始引用未改变
    }
}
```
- **输出结果：**
```
调用前 p.name: Bob
方法内 person.name: Charlie
调用后 p.name: Bob
```
- **解释：**
方法 `changeReference` 内部的 `person` 是原始引用的副本，重新赋值后指向新对象，但原始引用 `p` 仍指向原来的对象。


**理解 “方法内部可以通过引用副本修改对象的内容，但无法改变原始引用的指向。”：**
- `Person p = new Person("Bob");` 中 `p` 为原始引用，它存储的是 `new Person("Alice") ` 对象的地址。
- 方法内部的 `person` 即为 `p` 的副本，即引用副本，它储存的也是 `new Person("Alice") ` 对象的地址。
- 当通过试图引用副本修改对象的状态，`person.setName("Alice");`，即就是修改了该对象的状态。可以理解为 `person` 和 `p` 所指向的地址是一样的，那么 `.setName()` 传递给的是同一个对象，也就是原始对象，则原始对象的状态被改变。
- 当对引用副本重新赋值，`person = new Person("Charlie");` ，则只是改变了 `person` 所储存的地址，那么这时候 `person` 就和 `p` 以及原始对象没有任何关系了，自然也就无法对原始对象产生任何影响。

可以与C语言对比理解，引用也就是C中的指针，储存的就是地址。我们可以通过指针操作某个变量的值，但是指针本身没有任何意义。

**3. 数组的值传递**
数组是引用类型，传递时同样是传递引用的副本。方法内可以通过引用副本修改数组内容，但无法改变数组的指向。

```java
public class ArrayPassingExample {
    public static void modifyArray(int[] arr) {
        arr[0] = 100; // 修改数组内容
        arr = new int[]{200}; // 引用副本指向新数组
        System.out.println("方法内 arr[0]: " + arr[0]);
    }

    public static void main(String[] args) {
        int[] arr = {1, 2, 3};
        System.out.println("调用前 arr[0]: " + arr[0]);
        modifyArray(arr);
        System.out.println("调用后 arr[0]: " + arr[0]); // 数组内容被修改
    }
}
```
- **输出结果：**
```
调用前 arr[0]: 1
方法内 arr[0]: 200
调用后 arr[0]: 100
```

- **解释：**
方法 `modifyArray` 内部通过引用副本修改了数组的第一个元素（`arr[0] = 100`），但后续将引用副本指向新数组（`arr = new int[]{200}`）对原始数组无影响。


 **4. 字符串的特殊性**
字符串（`String`）在Java中是不可变对象（Immutable）。即使传递的是引用的副本，**修改字符串内容时实际上会创建新对象，原始字符串不会被修改。**


```java
public class StringPassingExample {
    public static void modifyString(String str) {
        str = str + " World"; // 创建新字符串对象
        System.out.println("方法内 str: " + str);
    }

    public static void main(String[] args) {
        String s = "Hello";
        System.out.println("调用前 s: " + s);
        modifyString(s);
        System.out.println("调用后 s: " + s); // 原始字符串未改变
    }
}
```

- **输出结果：**
```
调用前 s: Hello
方法内 str: Hello World
调用后 s: Hello
```

- **解释：**
字符串是不可变的，修改操作会生成新对象，原始字符串 `s` 仍然指向原来的值。

**关键点：**

- Java中**所有参数传递都是值传递**。对象传递的是引用的副本（即内存**地址的值**），方法内部通过该副本操作对象。
- 方法内重新赋值引用副本不会影响原始引用的指向。


**底层机制**
- **基本类型**：存储在栈内存中，传递时直接复制值。
- **对象/数组**：存储在堆内存中，栈中存储引用（内存地址），传递时复制引用的值。
- **方法调用**：形参是实参的副本，形参的修改不会影响实参，除非通过引用副本修改对象状态。
