## 7.1 绘制变量（含对象）在内存中的布局图。
### java内存布局


![](https://telegraph-image-5ms.pages.dev/file/AgACAgUAAyEGAASIfjD1AAIDDGqNsiQLOMDFzhJfoduaVo94XS8pAAJWF2sb5mpoVMe_Ur_QQoYFAQADAgADeAADPQQ.png)



 **栈内存 (Stack Memory)**
- 存储内容
	- **基本数据类型**：`int`, `float`, `boolean` 等原始类型的变量值
	- **对象引用**：指向堆内存中对象的指针（如 `Person p = new Person()` 中的 `p`）
	- **方法调用栈帧**：每个方法调用会生成一个栈帧（Stack Frame），包含：
	  - **局部变量表**：方法内部的局部变量
	  - **操作数栈**：用于计算中间结果
	  - **动态链接**：指向方法区的方法引用
	  - **方法返回地址**
- 特点
	- **线程私有**：每个线程有独立的栈内存，互不干扰
	- **快速分配**：内存分配通过指针移动实现（效率高）
	- **有限大小**：默认大小通常为 `1MB`（可通过 `-Xss` 调整）
	- **自动回收**：方法结束时栈帧自动弹出，内存立即释放
	- **常见异常**：`StackOverflowError`（递归过深）

```java
public void method() {
    int age = 25;          // 基本类型值直接存储在栈中
    Person p = new Person(); // 对象引用 `p` 在栈中，实际对象在堆中
}
```

 **堆内存 (Heap Memory)**
- 存储内容
	- **对象实例**：通过 `new` 创建的所有对象（包括数组）
	- **字符串常量池**（JDK 7+）：字符串字面量（如 `"Hello"`）
	- **其他运行时数据**：如线程共享的缓存对象
- 特点
	- **线程共享**：所有线程共享堆内存
	- **动态分配**：内存分配和回收由垃圾收集器（GC）管理
	- **分代管理**：堆分为以下区域优化 GC：
	  - **新生代**（Young Generation）：新对象在此分配
	    - Eden 区（伊甸园）
	    - Survivor 区（S0/S1）
	  - **老年代**（Old Generation）：长期存活的对象
	  - **元空间**（Metaspace, JDK 8+）：类元数据（取代永久代）
	- **可扩展**：可通过 `-Xms` 和 `-Xmx` 设置初始和最大堆大小
	- **常见异常**：`OutOfMemoryError`

```java
Person p = new Person(); // 对象实例在堆中
int[] arr = new int[3];  // 数组对象在堆中
String s = "Java";       // "Java" 存储在字符串常量池（堆中）
```
**方法区 (Method Area)**
- 存储内容
	- **类元数据**：类的结构信息（字段、方法、构造器等）
	- **运行时常量池**：类文件中定义的常量（如 `final` 常量）
	- **静态变量**（`static` 变量）
	- **JIT 编译后的代码**：热点代码的本地机器码
- 特点
	- **逻辑上属于堆**：但通常单独管理
	- **JDK 演变**：
	  - JDK 7 之前：称为 **永久代**（PermGen）
	  - JDK 8+：改为 **元空间**（Metaspace），使用本地内存

 **其他内存区域**
- **本地方法栈 (Native Method Stack)**  
   - 为 JVM 调用本地方法（Native Method）服务
   - 类似 Java 栈，但服务于 Native 代码
- **程序计数器 (Program Counter Register)**  
   - 记录当前线程执行到的字节码行号
   - 唯一不会发生 `OutOfMemoryError` 的区域



| 区域         | 存储内容                  | 线程共享性 | 生命周期       | 异常类型              |
|--------------|--------------------------|------------|----------------|-----------------------|
| **栈内存**   | 基本类型、对象引用        | 线程私有   | 方法调用周期   | StackOverflowError    |
| **堆内存**   | 对象实例、字符串常量池    | 线程共享   | 对象生命周期   | OutOfMemoryError      |
| **方法区**   | 类元数据、静态变量        | 线程共享   | JVM 生命周期   | OutOfMemoryError      |
| **本地方法栈**| Native 方法调用信息       | 线程私有   | 方法调用周期   | StackOverflowError    |

## 7.2 使用UML图例绘制类之间的继承关系、组合关系。



整体为一个矩形，第一层类名，第二层属性，第三层方法。

- 可见性修饰符
```
+：表示public 
-：表示private 
#：表示protected 
(空格)：表示默认default
```
- 属性：`可见性 名称: 类型`
- 方法：`可见性 名称(参数列表): 返回类型`
- 抽象成员（类和方法）：用斜体表示
- 接口：在类名上面多了\<\<interface>\>字段


**关系介绍**：

![](https://telegraph-image-5ms.pages.dev/file/AgACAgUAAyEGAASIfjD1AAIDDWqNsira6q1AtC0VYFscMzbIYFgbAAJXF2sb5mpoVKpqCncMyCXrAQADAgADeAADPQQ.png)




- **继承**：A "extends" B，即子类继承父类，空心箭头由子类A指向父类B。
- **实现**：A "implements" B，即类实现接口，空心箭头由类A指向它所实现的接口B。
- **单向关联**（Association）：A 持有 B 的引用，即 A 中包含 B 的成员变量。箭头由 A 指向 B 。
```java
class A {
    private B b; // A 持有 B 的引用
}

class B { }
```
- **双向关联**（谨慎使用）：A 和 B 彼此持有引用。无箭头。
```java
class A {
    private B b; // A 持有 B 的引用
}

class B {
    private A a; // B 也持有 A 的引用
}
```

- **单向依赖**（Dependency）：A 临时使用 B（如方法参数、局部变量或返回值），即 A 的方法中使用了 B 的实例。箭头由 A 指向 B 。
```java
class A {
    public void doSomething(B b) { // 方法参数依赖 B
        b.execute();
    }
}

class B { }
```
- **双向依赖**（应避免）：依赖关系本质是单向的，不存在严格意义的“双向依赖”。如果 A 依赖 B，同时 B 也依赖 A，通常说明设计存在问题，应重构为关联关系。
代码反例，应避免：
```java
class A {
    public void methodA(B b) {
        b.methodB(new A()); // A 依赖 B，B 又依赖 A
    }
}

class B {
    public void methodB(A a) { }
}
```

- **聚合**（Aggregation）：A "has a" B，空心菱形指向整体A。
整体由多个部分组成，但是他们具有各自的生命周期，脱离整体的个体依然存在，且可以被多个整体共享。如汽车和轮胎，学校和老师。
```java
class Car {
    private List<Tire> tires;  // 轮胎可独立存在
    
    public Car(List<Tire> tires) {
        this.tires = tires;    // 轮胎从外部传入
    }
}

class Tire { 
    // 轮胎不依赖特定汽车存在
}
```

- **组合**（Composition）：强聚合关系，实心菱形指向整体A。
个体的生命周期完全由整体控制，个体不可脱离整体而存在，个体仅属于一个整体，不可被共享。如公司和部门，订单和订单项，购物车和添加到购物车中的商品。
```java
class Company {
    private List<Department> departments;  // 部门生命周期由公司控制
    
    public Company() {
        // 部门在内部创建，无法独立存在
        departments = new ArrayList<>();
        departments.add(new Department("HR"));
        departments.add(new Department("Finance"));
    }
}

class Department {
    private String name;
    public Department(String name) {
        this.name = name;
    }
}
```

**聚合和组合的关键区别**：聚合的个体实例是由外部传入，而组合的个体实例是在整体类的内部new出来的。

一个示例：模拟购物车

`Item` 为添加到购物车中的商品，可以分为各种不同类的商品。
`Item` 与 `ShoppingCart` 为组合关系。
```java
public class ShoppingCart {
	 private ArrayList<Item> items;
	 public ShoppingCart() {
	 items = new ArrayList<>(); //items是在购物车中new出来的 依赖于购物车的生命周期
	 }
	 public void addItem(Item item) {
	 items.add(item);
	 }
	 public void removeItem(Item item) {
	 items.remove(item);
	 }
}
```
