# 考纲

本笔记严格按照ys老师给出的24级版本考纲进行编写，可用于查漏补缺。以下为考纲原文：

1. **语言基础**：
   - 了解Java语言的历史及Java程序的执行机制。
   - 掌握正确创建源文件、包声明、导入说明、所有形式的类声明、接口声明和实现、方法声明（包括用来开始执行一个类的主方法）、变量声明和标识符等。
   - 能识别Java编程语言中的所有关键词，并能正确构建标识符。
   - 掌握变量的初始化以及数组类型变量的初始化。
   - 了解所有基本数据类型的取值范围，掌握基本数据类型的常量表示形式。
   - 掌握String、StringBuilder类型的基本使用。

2. **运算符和函数**：
   - 掌握运算符（包括运算符的优先级、结合性以及计算）。
   - 掌握函数参数的传递（包括值传递和引用传递）。

3. **流控制和异常处理**：
   - 使用if和switch编写分支代码。
   - 使用各种形式的循环语句编写迭代代码，包括标签的和未标签的break和continue语句使用。
   - 编写使用异常和异常处理子句（try、catch、finally）的代码，以及编写带有异常处理的方法声明。
   - 掌握Java的异常类型的组织结构。
   - 掌握自定义异常类类型及相关使用。

4. **类类型**：
   - 在定义类、方法、实例变量、静态变量以及局部变量时，能够使用恰当的、语法允许的修饰符（如public、final、static、abstract等），并能够清楚准确阐述单独修饰符和联合修饰符的意义，以及在修饰符限定的声明条款上建立的包之间的关系所带来的影响。
   - 掌握访问控制修饰符；类的构造函数的定义及使用；类的继承，在继承关系发生时，要清楚理解子类和父类在构造函数方面、在成员方法、在数据成员之间发生的所有现象。

5. **接口类型**：
   - 接口的定义；接口和接口之间发生的关系；接口和类之间发生的关系。
   - 理解跨层多态。

6. **重载、覆盖和面向对象**：
   - 掌握面向对象的封装、继承和多态的概念，以及Java语言通过什么方式实现面向对象的这三大特征。
   - 明确面向对象的设计中封装的好处、编写类，以及诸如说明“是什么（is a）”和“有什么（has a）”之间关系的代码。
   - 掌握重载和覆盖的概念，以及相对应的实现方式。

7. **其他**：
   - 绘制变量（含对象）在内存中的布局图。
   - 使用UML图例绘制类之间的继承关系、组合关系。
