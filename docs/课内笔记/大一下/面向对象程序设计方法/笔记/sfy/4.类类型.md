# 4. 类类型

## 4.1 在定义类、方法、实例变量、静态变量以及局部变量时，能够使用恰当的、语法允许的修饰符（如public、final、static、abstract等），并能够清楚准确阐述单独修饰符和联合修饰符的意义，以及在修饰符限定的声明条款上建立的包之间的关系所带来的影响。

### 4.1.1 修饰符的分类与作用

- **访问修饰符（控制可见性）**
	- `public`: 无限制访问。
	- `protected`: 同一包内或不同包的子类可访问。
	- **默认（无修饰符）**: 同一包内可访问。
	- `private`: 仅当前类可访问。
- **非访问修饰符（控制行为特性）**
	- `static`: 静态成员（属于类而非实例）。
	- `final`: 不可修改（类不可继承，方法不可重写，变量不可重新赋值）。
	- `abstract`: 抽象（类不能实例化，方法无实现）。
	- `transient`: 序列化时忽略字段。
	- `volatile`: 保证多线程可见性。
	- `synchronized`: 方法同步（线程安全）。

### 4.1.2 修饰符的适用场景与规则

 **1. 类的修饰符**
| 修饰符          | 允许的修饰符组合       | 意义                                                                 |
|----------------|---------------------|--------------------------------------------------------------------|
| `public`       | `public abstract`   | 类对所有包可见；若为抽象类，需子类实现抽象方法。                                   |
| `abstract`     | `abstract final` ❌ | 类不能实例化，必须被继承。**不可与 `final` 同时使用**（矛盾：`final` 禁止继承）。       |
| `final`        | `final`             | 类不可被继承（如 `String`）。                                        |
| **默认（无）**  | 默认                | 仅在同一个包内可见。                                                  |
| `static`       | 仅内部类可用         | 静态嵌套类，不依赖外部类实例。                                          

```java
public abstract class Animal { }    // 可被继承的抽象类
final class MathUtils { }           // 不可继承的工具类
class PackagePrivateClass { }       // 仅同包可见
```

**2. 方法的修饰符**
| 修饰符          | 允许的修饰符组合                     | 意义                                                                 |
|----------------|-----------------------------------|--------------------------------------------------------------------|
| `public`       | `public static`                   | 所有包可访问的方法。                                                 |
| `protected`    | `protected final`                 | 同包或子类可访问的方法，且不可被重写。                                 |
| `private`      | `private static`                  | 仅当前类可访问。                                                    |
| **默认（无）**  | 默认                              | 同包内可访问。                                                      |
| `static`       | `public static`                   | 静态方法，通过类名调用。                                              |
| `final`        | `public final`                    | 方法不可被重写（常用于工具类或关键逻辑）。                             |
| `abstract`     | `public abstract`                 | 抽象方法，无实现体，需子类实现。**不可与 `private`、`static`、`final` 组合**。 |
| `synchronized` | `public synchronized`             | 线程同步方法。                                                      |

```java
public class Calculator {
    public static final double PI = 3.14;     // 常量
    public static int add(int a, int b) {     // 静态工具方法
        return a + b;
    }
    protected final void log(String msg) {    // 子类可见但不可重写
        System.out.println(msg);
    }
    private void internalProcess() { }        // 仅当前类可用
}
```
**3. 变量（实例变量/静态变量）的修饰符**
| 修饰符          | 允许的修饰符组合                | 意义                                                                 |
|----------------|------------------------------|--------------------------------------------------------------------|
| `public`       | `public static final`         | 全局常量（如 `public static final int MAX_VALUE = 100`）。          |
| `protected`    | `protected final`             | 子类或同包可见的不可变字段。                                         |
| `private`      | `private static`              | 类内部使用的静态字段。                                               |
| **默认（无）**  | 默认                          | 同包可见的字段。                                                    |
| `static`       | `static final`                | 静态常量，属于类而非实例。                                           |
| `final`        | `final`                       | 变量赋值后不可修改（常量或不可变对象）。                              |
| `transient`    | `transient`                   | 序列化时忽略该字段。                                                |
| `volatile`     | `volatile`                    | 多线程中保证字段的可见性。                                          |

```java
public class Config {
    public static final String ENV = "prod";  // 全局常量
    private static int counter = 0;           // 类内部计数器
    protected final String id;                // 子类可见的不可变字段
    transient byte[] cachedData;              // 不参与序列化
}
```
**4. 局部变量的修饰符**

**仅允许 `final`**：局部变量不可用其他修饰符。
  ```java
  void process() {
      final int localVar = 10;  // 正确
      // static int x = 5;     // 错误！局部变量不能用 static
  }
  ```



### 4.1.3 修饰符组合的典型用法与限制
 
- **常用组合**

| 组合                     | 应用场景                          | 示例                                     |
|-------------------------|---------------------------------|----------------------------------------|
| `public static final`   | 定义全局常量                      | `public static final int MAX_SIZE = 100` |
| `private static`        | 类内部静态工具字段或方法           | `private static Logger logger = ...`    |
| `protected abstract`    | 子类必须实现的抽象方法             | `protected abstract void init();`      |
| `public final`          | 禁止重写的方法或不可变类           | `public final class String { ... }`    |

- **禁止的组合**
	- `abstract + final`：抽象需子类实现，但 `final` 禁止继承（矛盾）。
	- `abstract + private`：私有方法不可被子类重写（无意义）。
	- `static + abstract`：静态方法属于类，无法被抽象化（矛盾）。
	- `final + volatile`：`final` 变量不可变，`volatile` 无意义。


### 4.1.4 包关系对修饰符的影响

**1. 跨包访问规则**
| 修饰符       | 同一包内 | 不同包的子类 | 不同包的非子类 |
|------------|--------|------------|-------------|
| `public`    | ✅      | ✅          | ✅           |
| `protected` | ✅      | ✅          | ❌           |
| **默认**    | ✅      | ❌          | ❌           |
| `private`   | ❌      | ❌          | ❌           |


```java
// 包 com.example
public class Parent {
    protected void method() { }
}

// 包 com.other
public class Child extends Parent {
    @Override
    protected void method() { }  // 允许：子类可访问 protected
}

// 包 com.another
public class Stranger {
    void test() {
        Parent p = new Parent();
        // p.method();  // 错误！非子类且不同包，无法访问 protected
    }
}
```
 **2. 关键影响**
- `public` 是跨包协作的基础。
- `protected` 用于允许子类扩展，但限制非子类访问。
- 默认修饰符强制包内封装，常用于模块化设计。
- `private` 实现类内部细节隐藏。



### 4.1.5 理解final

在Java中，`final`关键字用于修饰类、方法、变量和参数，其核心含义是**不可变性**。

 **1. `final` 修饰类**：被`final`修饰的类**不能被继承**。
- **典型用例**：
  - 防止类的行为被篡改（如`String`、`Integer`等不可变类）。
  - 工具类或安全性敏感的类（如加密相关类）。
- **示例**：
  ```java
  final class ImmutableClass {
      // 类内容无法被继承
  }
  // class SubClass extends ImmutableClass {} // 编译错误！
  ```

 **2. `final` 修饰方法**：被`final`修饰的方法**不能被子类重写**（Override）。
- **典型用例**：
  - 保护关键方法逻辑不被修改（如算法实现、模板方法中的固定步骤）。
  - 确保父类方法的行为一致性。
- **示例**：
  ```java
  class Parent {
      public final void criticalMethod() {
          // 子类无法重写此方法
      }
  }
  
  class Child extends Parent {
      // @Override public void criticalMethod() {} // 编译错误！
  }
  ```

**3. `final` 修饰变量**：被`final`修饰的变量**只能赋值一次**，后续不可修改。

**(1) 基本类型变量**
- 值不可变。
  ```java
  final int x = 10;
  // x = 20; // 编译错误！
  ```

**(2) 引用类型变量**
- 引用不可变（不能指向其他对象），但对象内部状态可能可变。
  ```java
  final List<String> list = new ArrayList<>();
  list.add("Java");       // 允许：修改对象内容
  // list = new LinkedList<>(); // 编译错误：不能更改引用
  ```

 **(3) 类成员变量**
- 必须在声明时或在**所有构造器中初始化**。
  ```java
  class MyClass {
      final int value; // 未初始化
      public MyClass(int v) {
          value = v; // 必须在构造器中赋值
      }
  }
  ```
**(4) 静态常量**
- `static final`组合定义全局常量。
  ```java
  public static final double PI = 3.14159;
  ```

 **4. `final`修饰参数**：方法参数被`final`修饰后，**不能在方法内修改**。
- **典型用例**：确保参数值在方法逻辑中不被意外更改。
  ```java
  void process(final int input) {
      // input = 5; // 编译错误！
  }
  ```

**5. `final`修饰局部变量**：局部变量被`final`修饰后，**初始化后不可变**。
- **典型用例**：Lambda表达式或匿名内部类中捕获的变量需为`final`或等效`final`。
  ```java
  void example() {
      final int localVar = 42;
      // localVar = 50; // 编译错误！
      Runnable r = () -> System.out.println(localVar); // Lambda使用final变量
  }
  ```


**总结**
| **修饰对象** | **作用**                          | **典型场景**                           |
|--------------|----------------------------------|---------------------------------------|
| 类           | 禁止继承                         | 不可变类（如`String`）、工具类         |
| 方法         | 禁止重写                         | 核心算法、模板方法                     |
| 变量         | 值/引用不可变                    | 常量、线程安全变量                     |
| 参数/局部变量| 禁止修改                         | Lambda表达式、代码可读性               |


### 4.1.6 理解static

在Java中，`static`关键字用于修饰类成员（变量、方法、代码块和内部类），使其**属于类本身而非类的实例**。
正是由于静态成员仅在类加载时执行一次，故它不依赖任何实例，只能访问其他静态成员。

 **1. 静态变量（类变量）**
- **定义**：用`static`修饰的变量，属于类，所有实例共享同一份内存。
- **特点**：
  - 在类加载时初始化，生命周期持续到程序结束。
  - 存储在方法区（Method Area），而非堆内存。
  - 可以直接通过类名访问（推荐），如`ClassName.staticVar`。
- **示例**：
  ```java
  class Counter {
      static int count = 0; // 静态变量
      Counter() {
          count++; // 所有实例共享计数
      }
  }
  
  public class Main {
      public static void main(String[] args) {
          new Counter();
          new Counter();
          System.out.println(Counter.count); // 输出：2
      }
  }
  ```

 **2. 静态方法**
- **定义**：用`static`修饰的方法，属于类，无需实例即可调用。
- **特点**：
  - 只能直接访问静态成员（变量/方法），不能访问实例成员。
  - 不能使用`this`或`super`关键字。
  - 常用于工具方法（如`Math.sqrt()`）或单例模式。
  - 子类定义的同名静态方法会隐藏（Hide）父类方法而非重写（Override）。
- **示例**：
  ```java
  class MathUtils {
      public static int add(int a, int b) {
          return a + b;
      }
  }
  
  public class Main {
      public static void main(String[] args) {
          int sum = MathUtils.add(3, 5); // 直接调用
          System.out.println(sum); // 输出：8
      }
  }
  ```

**3. 静态代码块**
- **定义**：用`static { ... }`包裹的代码块，在类加载时执行一次。
- **用途**：初始化静态变量或执行一次性操作（如加载驱动）。
- **示例**：
  ```java
  class Database {
      static {
          System.out.println("加载数据库驱动...");
          // 实际代码可能为：Class.forName("com.mysql.jdbc.Driver");
      }
  }
  
  public class Main {
      public static void main(String[] args) {
          new Database(); // 首次使用类时触发静态代码块
      }
  }
  ```

 **4. 静态内部类**
- **定义**：用`static`修饰的嵌套类，不依赖外部类实例。
- **特点**：
  - 可独立创建实例，如`Outer.Inner inner = new Outer.Inner();`。
  - 只能访问外部类的静态成员。
- **示例**：
  ```java
  class Outer {
      static int outerStaticVar = 10;
      
      static class Inner {
          void print() {
              System.out.println("外部类的静态变量：" + outerStaticVar);
          }
      }
  }
  
  public class Main {
      public static void main(String[] args) {
          Outer.Inner inner = new Outer.Inner();
          inner.print(); // 输出：外部类的静态变量：10
      }
  }
  ```

 **5. 静态导包**
- **定义**：通过`import static`导入类的静态成员，简化调用。
- **示例**：
  ```java
  import static java.lang.Math.PI;
  import static java.lang.Math.sqrt;
  
  public class Main {
      public static void main(String[] args) {
          System.out.println(PI); // 直接使用
          System.out.println(sqrt(9)); // 输出：3.0
      }
  }
  ```
  
 **关键注意事项**
- **生命周期与内存**：
   - 静态成员在类加载时初始化，销毁于程序结束。
   - 实例成员依赖于对象，对象回收后实例成员消失。
- **访问限制**：
   - 静态方法中不能直接访问实例变量/方法（需通过对象实例）。
   - 实例方法可以自由访问静态成员和实例成员。
- **设计场景**：
   - **工具类**：所有方法设为静态（如`Collections`、`Arrays`）。
   - **全局配置**：静态变量存储共享数据（如`public static final`常量）。
   - **单例模式**：通过静态方法控制实例创建。
- **线程安全**：
   - 静态变量是共享资源，多线程环境下需同步控制（如加锁）。

### 4.1.7 关于理解子类的静态方法只能隐藏父类的同名静态方法而非重写

在Java中，子类定义的同名静态方法会隐藏（Hide）父类方法而非重写（Override），这是由静态方法的类级别绑定特性决定的。

- **静态方法与实例方法的本质区别**
	- **静态方法（Static Method）**：
	  - 属于类本身，而非类的实例。
	  - 在编译时通过**类名**或**引用类型**直接绑定。
	  - 不参与多态性（运行时动态绑定）。
	- **实例方法（Instance Method）**：
	  - 属于对象实例。
	  - 在运行时通过**对象实际类型**动态绑定。
	  - 支持多态性，允许子类重写父类方法。

**静态方法的“隐藏”行为**

当子类定义与父类同名的静态方法时：

- **父类的静态方法未被覆盖**，而是被**隐藏**。
- 调用哪个方法取决于**引用类型**（编译时决定），而非对象实际类型。
- 
  ```java
  class Parent {
      public static void print() {
          System.out.println("Parent Static Method");
      }
  }
  
  class Child extends Parent {
      public static void print() {
          System.out.println("Child Static Method");
      }
  }
  
  public class Test {
      public static void main(String[] args) {
          Parent p = new Child();
          p.print();  // 输出 "Parent Static Method"（依赖引用类型 Parent）
  
          Child c = new Child();
          c.print();   // 输出 "Child Static Method"（依赖引用类型 Child）
      }
  }
  ```
- **这样理解“隐藏”：当发生隐藏时，其实可以直接把static方法理解为 没有多态的普通方法，那么就不考虑父子类的继承关系，对象声明的是哪个类就调用哪个类的函数。**

**实例方法的“重写”行为**
 
当子类重写父类实例方法时：

- 父类方法被覆盖。
- 调用哪个方法取决于**对象实际类型**（运行时决定）。
- 
  ```java
  class Parent {
      public void show() {
          System.out.println("Parent Instance Method");
      }
  }
  
  class Child extends Parent {
      @Override
      public void show() {
          System.out.println("Child Instance Method");
      }
  }
  
  public class Test {
      public static void main(String[] args) {
          Parent p = new Child();
          p.show();  // 输出 "Child Instance Method"（依赖对象类型 Child）
      }
  }
  ```

**关键对比：隐藏 vs 重写**
| **特性**         | **静态方法（隐藏）**                | **实例方法（重写）**                |
|------------------|-----------------------------------|-----------------------------------|
| **绑定时机**     | 编译时（基于引用类型）              | 运行时（基于对象实际类型）          |
| **多态性**       | 不支持                            | 支持                              |
| **方法可见性**   | 父类方法仍存在，但被隐藏            | 父类方法被覆盖，不可直接访问        |
| **调用方式**     | 推荐通过类名调用（如 `Parent.print()`） | 通过对象调用（如 `obj.show()`）     |



**为什么静态方法不能重写？**
- **设计原则**：静态方法属于类级别，与对象实例无关，因此不需要多态性支持。
- **避免混淆**：若允许静态方法重写，可能导致以下问题：
  - 通过父类引用调用时，行为与实例方法不一致。
  - 破坏静态方法的“全局工具”定位（如 `Math.sqrt()`）。



## 4.2 掌握访问控制修饰符；类的构造函数的定义及使用；类的继承，在继承关系发生时，要清楚理解子类和父类在构造函数方面、在成员方法、在数据成员之间发生的所有现象。


### 4.2.1 构造函数的定义及使用

- **构造函数的定义**
   - 方法名必须与类名**完全相同**。
   - **没有返回类型**（连 `void` 也不能写）。
   - 可以包含参数（支持重载）。
   - 访问修饰符可以是 `public`、`protected`、`private` 或默认（包私有）。
   - 构造函数**不能被覆盖**。子类不继承父类的构造函数，且由于构造函数的名字必须与类名完全一致，而子类的类名与父类的类名不同，因此子类中无法定义一个与父类构造函数同名的方法。
- 默认构造函数：
   - 如果类未显式定义构造函数，Java会**自动生成一个无参构造函数**（默认构造函数）。
   - 若手动定义了任意构造函数，默认的无参构造函数将不再生成，需显式定义。
```java
// 无参构造函数（默认构造函数）
public Car() {
    // 可初始化默认值
}
```

- **构造函数的使用**
	- **对象初始化**：通过 `new` 关键字调用构造函数，创建对象并初始化属性。
   ```java
   Car myCar = new Car("Red", "Toyota");
   ```
	- **重载构造函数**：同一类中可定义多个不同参数的构造函数，根据需求选择。
   ```java
   public Car(String color) {
       this.color = color;
       this.model = "Unknown";
   }
   ```
	- **`this` 关键字**： 用于调用当前类的其他构造函数（必须放在构造函数首行）。
   ```java
   public Car() {
       this("Black", "Unknown"); // 调用带参构造函数
   }
   ```
	- **`super` 关键字**： 子类构造函数中需先调用父类构造函数（默认调用父类无参构造 `super()`）。 若父类没有无参构造函数，子类必须显式调用父类的有参构造函数。
   ```java
   class Animal {
       public Animal(String name) { /* ... */ }
   }

   class Dog extends Animal {
       public Dog(String name) {
           super(name); // 必须显式调用父类构造函数
       }
   }
   ```

- **注意事项**
	- **继承与构造函数**：
	   - 构造函数**不能被继承**，子类必须定义自己的构造函数。
	   - 若父类没有无参构造，子类构造函数必须显式调用父类有参构造。
	- **私有构造函数**： 用于单例模式或工具类，禁止外部实例化。
   ```java
   public class Singleton {
       private Singleton() {}

       public static Singleton getInstance() { /* ... */ }
   }
   ```
	- **初始化顺序**：
	   - 父类构造函数 → 子类构造函数。
	   - 实例初始化块（`{ ... }`）会在构造函数之前执行。


### 4.2.2 类的继承

**1. 构造函数的行为**
- **隐式调用父类无参构造**：  
  子类构造函数必须**先调用父类构造函数**（通过 `super()`）。如果未显式调用，编译器会自动插入 `super()`（要求父类必须有无参构造函数）。
  ```java
  class Parent {
      Parent() { System.out.println("Parent构造"); }
  }
  class Child extends Parent {
      Child() { 
          // 隐含 super();
          System.out.println("Child构造"); 
      }
  }
  ```

- **显式调用父类有参构造**：  
  若父类没有无参构造，子类必须**显式调用父类有参构造**，且必须放在子类构造函数的第一行。
  ```java
  class Parent {
      Parent(int x) { System.out.println("Parent构造: " + x); }
  }
  class Child extends Parent {
      Child() {
          super(10); // 必须显式调用
          System.out.println("Child构造");
      }
  }
  ```

- **构造链的执行顺序**：  
  父类构造函数 → 父类实例初始化块 → 子类实例初始化块 → 子类构造函数。
  ```java
  // 示例输出顺序：
  Parent实例块 → Parent构造 → Child实例块 → Child构造
  ```

 **2. 成员方法的行为**

- **方法重写（Override）**：  
  子类可以重写父类的非 `private`、非 `final`、非 `static` 的实例方法，需满足：
  - **方法签名一致**（方法名、参数列表相同）。
  - 返回类型可以是父类方法返回类型的子类（协变返回类型）。
  - 访问权限不能比父类更严格（如父类 `protected`，子类不能改为 `private`）。
  - 不能抛出比父类方法更宽泛的检查异常。
  ```java
  class Parent {
      protected Number getValue() { return 1; }
  }
  class Child extends Parent {
      @Override
      public Integer getValue() { return 2; } // 协变返回类型
  }
  ```

- **方法隐藏（Hide）**：  
  如果子类定义与父类同名的 `static` 方法，父类的静态方法会被**隐藏**（非覆盖）。调用时取决于引用类型。
  ```java
  class Parent {
      static void print() { System.out.println("Parent"); }
  }
  class Child extends Parent {
      static void print() { System.out.println("Child"); }
  }
  
  Parent p = new Child();
  p.print(); // 输出 Parent（静态方法看引用类型）
  ```

- **`super` 调用父类方法**：  
  子类可以通过 `super.方法名()` 显式调用父类被重写的方法。
  ```java
  class Child extends Parent {
      void show() {
          super.show(); // 调用父类方法
          System.out.println("Child");
      }
  }
  ```

 **3. 数据成员的行为**
- **字段隐藏（Shadowing）**：  
  如果子类定义与父类同名的字段，父类的字段会被隐藏。访问时取决于引用类型。
  ```java
  class Parent {
      String name = "Parent";
  }
  class Child extends Parent {
      String name = "Child";
  }
  
  Parent p = new Child();
  System.out.println(p.name); // 输出 Parent（字段看引用类型）
  ```

- **直接访问父类字段**：  
  子类可以通过 `super.字段名` 访问父类被隐藏的字段。
  ```java
  class Child extends Parent {
      void printNames() {
          System.out.println(super.name); // 父类字段
          System.out.println(this.name);  // 子类字段
      }
  }
  ```

- **继承与访问权限**：  
  子类只能直接访问父类的 `public`、`protected` 和默认（包私有）字段，无法直接访问 `private` 字段。
  ```java
  class Parent {
      private int secret = 123;
      protected int code = 456;
  }
  class Child extends Parent {
      void show() {
          // System.out.println(secret); // 编译错误（private）
          System.out.println(code);      // 允许访问（protected）
      }
  }
  ```

 **4. 多态与动态绑定**
- **方法调用的多态性**：  
  实例方法的调用基于对象的实际类型（动态绑定），而字段和静态方法基于引用类型。
  ```java
  class Animal {
      String name = "Animal";
      void sound() { System.out.println("Animal sound"); }
  }
  class Dog extends Animal {
      String name = "Dog";
      void sound() { System.out.println("Bark"); }
  }
  
  Animal a = new Dog();
  a.sound();    // 输出 Bark（方法动态绑定）
  System.out.println(a.name); // 输出 Animal（字段静态绑定）
  ```
 **5. 特殊场景与注意事项**

- **`final` 关键字**：
   - `final` 类不能被继承。
   - `final` 方法不能被子类重写。
   - `final` 字段必须初始化且不可修改。
- **抽象类与继承**：
   - 子类必须实现父抽象类的所有抽象方法，否则子类也需声明为抽象类。
- **构造函数的私有化**：
   - 如果父类构造函数是 `private`，子类无法继承（无法调用 `super()`）。
- **`@Override` 注解**：  
   推荐在重写方法时添加 `@Override`，以便编译器检查方法签名是否正确。

### 4.2.3 关于只能调用声明引用类型所拥有的方法

如果你通过一个父类类型的变量引用一个子类对象，那么这就会导致，你**只能调用那些在父类中定义的方法**。**即使该对象本身拥有额外的方法**（定义在子类中），也不能通过父类引用直接访问这些方法。

**举例说明**：


```java
class Animal {
    public void eat() {
        System.out.println("Animal is eating.");
    }
}

class Dog extends Animal {
    public void bark() {
        System.out.println("Dog is barking.");
    }
}
```
 使用父类引用指向子类对象

```java
Animal myPet = new Dog();
myPet.eat();   // 合法：调用从 Animal 继承的方法
myPet.bark();  // 编译错误：bark() 不在 Animal 类中
```

虽然 `myPet` 实际上是一个 `Dog` 对象，并且确实有 `bark()` 方法，但由于 `myPet` 的类型是 `Animal`，编译器只允许你调用 `Animal` 类中声明的方法。


 **为什么这样设计？**

这是 Java 的 **静态类型检查机制** 所决定的：
- **编译时**：Java 根据变量的**声明类型**来决定哪些方法可以被调用。
- **运行时**：JVM 根据变量所引用的**实际对象类型**来决定具体执行哪个方法体（这就是多态）。

所以：

| 情况 | 能否调用 |
|------|-----------|
| 方法在父类中定义，子类重写 | ✅ 可以调用，执行子类实现 |
| 方法只在子类中定义 | ❌ 不能通过父类引用调用 |


**如果你想调用子类特有的方法怎么办？**

你需要进行 **向下转型（downcasting）**：

```java
Animal myPet = new Dog();

// 显式向下转型为 Dog 类型
Dog dogPet = (Dog) myPet;

dogPet.bark();  //  现在可以调用了
```

 注意：
- 如果 `myPet` 实际不是 `Dog` 类型，会抛出 `ClassCastException`。
- 建议使用 `instanceof` 进行判断后再转型：

```java
if (myPet instanceof Dog) {
    Dog dogPet = (Dog) myPet;
    dogPet.bark();
}
```
**总结**

| 引用类型 | 实际对象 | 可调用方法范围 |
|----------|-----------|------------------|
| 父类     | 子类      | 仅限父类中定义的方法 |
| 子类     | 子类      | 父类 + 子类中的所有方法 |
| 接口     | 实现类    | 仅限接口中定义的方法 |
| 抽象类   | 具体子类  | 仅限抽象类中定义的方法（包括可能的已实现方法） |

**其实就是只能调用所声明的引用类型所拥有的方法**（子类拥有父类的所有方法），而不论该对象真实的类型是什么



### 4.2.4 this 和 super 全面理解

 **`this` 关键字**：`this` 表示当前正在操作的对象本身。

- **解决变量名冲突**：当局部变量（如方法参数）与实例变量（类的字段）同名时，用 `this` 明确引用实例变量。
```java
class Person {
    private String name;

    public Person(String name) {
        this.name = name; // this.name 表示实例变量，name 是参数
    }
}
```
- **调用本类的其他构造函数**：通过 `this()` 调用当前类的其他构造函数（必须在构造函数的第一行）。

```java
class Rectangle {
    int width, height;

    // 构造函数 1
    public Rectangle() {
        this(0, 0); // 调用构造函数 2
    }

    // 构造函数 2
    public Rectangle(int width, int height) {
        this.width = width;
        this.height = height;
    }
}
```

- **返回当前对象**：在方法中返回 `this` 可以实现链式调用（如 `builder` 模式）。
```java
class StringBuilder {
    private String content = "";

    public StringBuilder append(String str) {
        this.content += str; // 修改当前对象的 content
        return this; // 返回当前对象，支持链式调用
    }
}

// 使用示例
new StringBuilder().append("Hello").append(" World");
```

**`super` 关键字**：`super` 表示当前对象的父类部分。




- **调用父类的构造函数**：通过 `super()` 调用父类的构造函数（必须在子类构造函数的第一行）。
```java
class Animal {
    public Animal() {
        System.out.println("Animal constructor");
    }
}

class Dog extends Animal {
    public Dog() {
        super(); // 调用父类 Animal 的构造函数
        System.out.println("Dog constructor");
    }
}

// 输出：
// Animal constructor
// Dog constructor
```

- **访问父类的成员**：当子类重写了父类的方法或变量时，用 `super` 访问父类的原始方法或变量。
```java
class Parent {
    int value = 100;
    void display() {
        System.out.println("Parent display");
    }
}

class Child extends Parent {
    int value = 200;

    void display() {
        System.out.println("Child display");
    }

    void show() {
        System.out.println("Child's value: " + this.value);      // 输出 200（当前类的 value）
        System.out.println("Parent's value: " + super.value);    // 输出 100（父类的 value）
        super.display(); // 调用父类的 display 方法
    }
}
```

- **调用父类的被覆盖方法**：在子类中调用父类的同名方法（如重写后保留父类逻辑）。

```java
class Animal {
    void speak() {
        System.out.println("Animal speaks");
    }
}

class Cat extends Animal {
    @Override
    void speak() {
        super.speak(); // 调用父类的 speak 方法
        System.out.println("Cat meows");
    }
}

// 输出：
// Animal speaks
// Cat meows
```

 **关键规则**
   - 子类构造函数中必须显式或隐式调用父类构造函数（`super()` 或默认的无参构造）。
   - `super()` 和 `this()` 都必须是构造函数中的第一条语句，且不能同时存在。

   - `this` 和 `super` 不能在静态方法或静态代码块中使用（因为它们依赖对象实例）。

   - `super` 只能直接访问父类的成员，不能跨多级父类（如 `super.super` 是非法的）。

### 4.2.5 关于到底为什么不能同时调用 `super()` 和 `this()`

下面通过一个具体的例子来说明如果允许同时调用 `super()` 和 `this()` 可能会导致的问题：

假设有一个父类 `MySuper` 和一个子类 `MyClass`，它们的构造函数如下：

 父类 `MySuper`

```java
public class MySuper {
    MySuper() {
        System.out.println("MySuper: 无参构造函数被调用");
    }

    MySuper(int i) {
        System.out.println("MySuper: 带参构造函数被调用，参数为 " + i);
    }
}
```

子类 `MyClass`

```java
public class MyClass extends MySuper {
    MyClass() {
        super(); // 调用父类的无参构造函数
        System.out.println("MyClass: 无参构造函数被调用");
    }

    MyClass(int i) {
        super(i); // 调用父类的带参构造函数
        this(); // 调用本类的无参构造函数
        System.out.println("MyClass: 带参构造函数被调用，参数为 " + i);
    }

    public static void main(String[] args) {
        MyClass obj = new MyClass(5);
    }
}
```

**问题分析**

1. **构造函数调用链**：
   - 当创建 `MyClass` 的实例时（`new MyClass(5)`），首先执行 `MyClass` 的带参构造函数。
   - 带参构造函数的第一行是 `super(i)`，调用父类 `MySuper` 的带参构造函数。
   - 接下来，带参构造函数调用 `this()`，即调用 `MyClass` 的无参构造函数。
   - 无参构造函数的第一行是 `super()`，调用父类的无参构造函数。

2. **执行流程**：
   - `new MyClass(5)` 触发 `MyClass` 的带参构造函数。
   - 调用 `super(i)`，输出 `MySuper: 带参构造函数被调用，参数为 5`。
   - 调用 `this()`，触发 `MyClass` 的无参构造函数。
   - 无参构造函数调用 `super()`，输出 `MySuper: 无参构造函数被调用`。
   - 返回到 `MyClass` 的带参构造函数，输出 `MyClass: 带参构造函数被调用，参数为 5`。

 **输出结果**

```
MySuper: 带参构造函数被调用，参数为 5
MySuper: 无参构造函数被调用
MyClass: 无参构造函数被调用
MyClass: 带参构造函数被调用，参数为 5
```

**问题所在**

从输出结果可以看出，父类 `MySuper` 的构造函数被调用了两次，一次是带参构造函数，一次是无参构造函数。这会导致父类的初始化过程被重复执行，可能引发以下问题：

1. **资源浪费**：父类的构造函数被多次调用，重复执行初始化逻辑，浪费系统资源。
2. **初始化混乱**：父类的状态可能被多次初始化，导致对象的状态不一致或混乱。
3. **难以维护**：构造函数的调用链变得复杂，难以理解和维护，增加了代码出错的风险。

**正确的做法**

为了避免这些问题，Java 规定构造函数的第一行只能是 `super()` 或 `this()`，不能同时使用两者。正确的写法是根据需求选择调用父类的构造函数或本类的其他构造函数。

**修正后的代码**

```java
public class MyClass extends MySuper {
    MyClass() {
        super(); // 调用父类的无参构造函数
        System.out.println("MyClass: 无参构造函数被调用");
    }

    MyClass(int i) {
        super(i); // 调用父类的带参构造函数
        System.out.println("MyClass: 带参构造函数被调用，参数为 " + i);
    }

    public static void main(String[] args) {
        MyClass obj = new MyClass(5);
    }
}
```
**修正后的输出结果**
```
MySuper: 带参构造函数被调用，参数为 5
MyClass: 带参构造函数被调用，参数为 5
```

这样可以确保父类的构造函数只被调用一次，避免重复初始化和资源浪费。
