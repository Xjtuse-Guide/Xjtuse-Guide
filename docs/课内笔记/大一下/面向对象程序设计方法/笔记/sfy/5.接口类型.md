# 5. 接口类型

## 5.1 接口的定义；接口和接口之间发生的关系；接口和类之间发生的关系。

### 5.1.1 Java 接口的定义  
**接口（Interface）** 是 Java 中一种完全抽象的引用类型，用于定义一组方法签名（规范）和常量（`public static final`），但不能包含实例字段或具体的方法实现（Java 8 之前）。接口的核心作用是**定义行为规范**，强制实现类遵循统一的契约。  

- **Java 8+**：允许定义**默认方法**（`default` 修饰，提供默认实现）和**静态方法**（`static` 修饰，直接通过接口调用）。  
- **Java 9+**：支持**私有方法**（`private` 修饰，供接口内部复用代码）。  


 接口的核心作用  
- **解耦**：分离定义与实现，降低模块间依赖。  
- **多态**：通过接口类型统一操作不同实现类。  
- **扩展性**：通过默认方法支持接口的平滑演进。  


### 5.1.2 接口与接口之间的关系 

接口之间通过**继承**（`extends`）建立关系，且支持**多继承**（一个接口可以继承多个接口）。  

```java
interface A { void methodA(); }
interface B { void methodB(); }

// 接口C继承A和B，合并两者的方法
interface C extends A, B { 
    void methodC(); 
}
```
- 子接口（如 `C`）会继承所有父接口的方法，实现类需要覆写所有抽象方法（包括父接口的）。  
- 多继承不存在类多继承的“菱形问题”，因为接口没有实现冲突（只有方法签名，无具体逻辑）。  


### 5.1.3 接口与类之间的关系  

类通过 `implements` 关键字**实现接口**，需遵循以下规则：  

1. **单实现或多实现**  
- 一个类可以实现**多个接口**，但只能继承一个类。  
- 实现接口的类必须覆写接口中所有抽象方法（除非自身是抽象类）。  


```java
class MyClass implements A, B {
    @Override
    public void methodA() { /* 实现 */ }
    @Override
    public void methodB() { /* 实现 */ }
}
```

 2. **默认方法的灵活性**  


- **直接使用接口的默认方法**
```java
interface Loggable {
    // 默认方法：提供日志输出的默认实现
    default void log(String message) {
        System.out.println("[LOG] " + message);
    }
}

class UserService implements Loggable {
    // 无需覆写 log()，直接继承默认实现
    public void register(String username) {
        log("Registering user: " + username);
        // 其他逻辑...
    }
}

public class Main {
    public static void main(String[] args) {
        UserService service = new UserService();
        service.register("Alice"); 
        // 输出：[LOG] Registering user: Alice
    }
}
```


- **类覆写默认方法**
```java
interface Loggable {
    default void log(String message) {
        System.out.println("[LOG] " + message);
    }
}

class FileService implements Loggable {
    // 覆写默认方法，自定义日志行为
    @Override
    public void log(String message) {
        System.out.println("[FILE_LOG] " + message);
    }

    public void saveFile(String fileName) {
        log("Saving file: " + fileName);
    }
}

public class Main {
    public static void main(String[] args) {
        FileService service = new FileService();
        service.saveFile("data.txt"); 
        // 输出：[FILE_LOG] Saving file: data.txt
    }
}
```
- **多接口默认方法冲突** ： 若类 implements 的多个接口有同名默认方法，实现类**必须显式覆写**以避免冲突。  
```java
interface A {
    default void doSomething() {
        System.out.println("A's default method");
    }
}

interface B {
    default void doSomething() {
        System.out.println("B's default method");
    }
}

// 实现类必须显式解决冲突
class MyClass implements A, B {
    // 必须覆写 doSomething()，否则编译报错
    @Override
    public void doSomething() {
        // 选择调用某个接口的默认方法
        A.super.doSomething(); 
        // 或者完全自定义实现
    }
}

public class Main {
    public static void main(String[] args) {
        MyClass obj = new MyClass();
        obj.doSomething(); // 输出：A's default method
    }
}
```


## 5.2 理解跨层多态。

跨层多态指的是：**不同层次的类（可能没有直接继承关系）通过接口，以统一的方式被调用**。

**场景**：两个无继承关系的类实现同一接口，通过接口类型统一调用。  
```java
// 定义接口
interface Flyable {
    void fly();
}

// 不同类层次的类实现同一接口
class Bird implements Flyable {
    @Override
    public void fly() {
        System.out.println("鸟用翅膀飞");
    }
}

class Airplane implements Flyable {
    @Override
    public void fly() {
        System.out.println("飞机用引擎飞");
    }
}

// 通过接口类型调用
public class Main {
    public static void main(String[] args) {
        Flyable[] flyables = {new Bird(), new Airplane()};
        for (Flyable obj : flyables) {
            obj.fly(); // 同一方法，不同实现
        }
    }
}
```
**输出**：
```
鸟用翅膀飞
飞机用引擎飞
```
`Bird` 和 `Airplane` 属于不同类层次，但通过实现 `Flyable` 接口，实现了跨层的多态调用。
