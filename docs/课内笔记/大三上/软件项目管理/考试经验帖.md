# 软件项目管理考试经验帖

## 李彦筱

这门课就当成马原看就行了，我们软件也有自己的马原（）

考试题目主要包含判断、填空、选择、简答和计算题。其中最难的是简答题，老师非常喜欢从 ppt 的角落中找知识点考成简答。

计算题的题目是完全固定的：只包含以下三个固定出题点：

- 项目整体管理的净现值分析
- 项目成本管理的挣值分析
- 项目时间管理的关键路径分析法

这些出题点都不会考太难的题目，属于学过就基本会做的，计算题的 20 分一定要拿到。

对于复习方式，我个人认为按照学习马原的方式学这门课就行。如果你习惯思政课平时不听，最后一次背完，那没有问题；如果你习惯平时学一章节就背一章，那也可以。

老师不给 ppt，因此建议上课拍一下，或者课程结束之后去 class 平台看回放。

> 不过，即使你不想听课，平时上课也一定要来，因为老师有的时候会让大家做上课刚讲的题，交上去当点名，据说没交的话平时分扣的非常多。
>
> 老师在上课的时候说不定会透露一下简答题要考什么，像 2022 级第一道简答题是「什么是挣值分析」，老师上课时就说过要把挣值分析的定义这行字完全背下来。

## 袁泉

23级。授课老师是宋永红老师。

上课得去，就1次作业，写题交题点了5次名，没缺勤平时分就给满，缺了会扣很多。注意宋老师不接受补假条，除非真的特殊情况很难请假。0.5学分的综合训练要找靠谱的人把项目做好，验收需要每个人讲各自分工负责的内容，整体完成度不错还是能比较顺利通过的，但如果问题略大会被拷打得比较厉害。

我是大二跨选也挺推荐大二跨选的，这种要求比较多的课放课多的大二去上还比较接近无感，大三下应该都挺忙课程以外的东西了还得上一个请假都难的课感觉挺心累的。

考试这次没有填空题了，但最容易拿分的计算题占比缩水。剩下的单选判断简答解答，就全是考上课在讲的概念，我几乎全程听课还记了不少笔记试图听出点重点，但上课除了计算题那几个真的完全没讲过重点是什么。

俊泉学长笔记里有不少流程的图示，左边是项目章程等输入文件，经过某过程，例如得到右边项目范围说明书等输出文件。这种图示老师在课堂上也花了很多时间讲还好多，但我觉得很多毫无逻辑完全背不了，所以问了一下老师，老师很笃定地说这些图示不会考。

复习还是建议ppt吧，但老师也不发，可能得录播自己截图或者让agent来干活，我对着自己的笔记复习感觉很多也不全。
